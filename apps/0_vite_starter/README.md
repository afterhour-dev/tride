# Threejs starter sa WebGL

Treba da se koristi kao starter za aplikacije koje ce koristiti samo WebGL renderer, što se neće događati često jer u budućnosti prelazim na WebGPU.

## Namera / Intent

App je napravljen kao starter, i tu je samo kao početni template za druge aplikacije.

## Šta treba objasniti u detalje

Redosled renderinga. Odnosno šta se sve dešava tokom jedne scene i koje stvari yavise jedna od druge.
