# textures - uv unwrapping

Learning about uv unwrapping

We used sample texture downloaded from [here](https://3dtextures.me/2019/04/16/door-wood-001/), which is very popular texture.

## Šta treba objasniti u detalje

- Explain how texture is placed on geometry, is it random or not
- the texture is being stretched or squeezed in different ways to cover the geometry
- this is called uv unwrapping and it's like unwrapping an christmas candy or a candy wrap to make it flat
- each vertex will have a 2D coordinate on a flat plane (usually a square)

- uv coordinates are generated by Three.js
- if you create your own geometry you'll have to specify the uv coordinates
- if you're making the geometry using a 3D software, you'll also have to do the UV unwrapping
