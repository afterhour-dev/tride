# Scroll based animation - parallax

This app is made for learning how we can do scroll based animations in threejs, we want to integrate threejs properly with HTML content.

This project is continuation of previous lesson. Continuation of project will be in next lesson.

## Namera / Intent

Learn how to utalize techique of scroll based animation with Three.js.

## Šta treba objasniti u detalje

- parallax is the action of seeing one object through different observation points; this is done naturally by our eyes and it's how we feel the depth of things
- we applied parallax effect by making the camera move horizontally and vertically according to the mouse movement
