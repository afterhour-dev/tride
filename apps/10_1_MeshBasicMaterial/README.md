## Namera / Intent

## Šta treba objasniti u detalje

- materials are used to put color on each visible pixel of the geometries
- algoritms that decide on that color of each pixel are written in programs called shaders
- Three.js has many built-in materials with pre-made shaders

- MeshBasicMaterial is the most "basic" material but there are multiple properties that we haven't covered yet, because these properties can be used on other materials we are going to see in other lessons
