# Raycaster - Mouse Click event

In this app we explore raycaster by using it with a mouse "click" event.
This lesson is continuation of previous one.

## Namera / Intent

App is made to learn raycaster, precisely to learn how to use it with click event.

## Šta treba objasniti u detalje

- we will use `currentIntersect` variable from previous lesson to use it inside click handler so we can do something with intersected object in mentioned handler

- I made middle mesh box just for practice where if he is intersected, if you click it will rotate
