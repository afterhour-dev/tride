Both `Math.sin()` and `Math.cos()` in JS/TS take radians and return values in the range `[-1, 1]`. Your directional description matches a full cycle from `0` to `2π`:

| radians | 0 | π/2 | π | 3π/2 | 2π |
|---|---|---|---|---|---|
| `sin` | 0 | 1 | 0 | -1 | 0 |
| `cos` | 1 | 0 | -1 | 0 | 1 |

So as radians grow from `0`:
- `sin`: `0 → 1 → 0 → -1 → (0 again at 2π)`
- `cos`: `1 → 0 → -1 → 0 → (1 again at 2π)`

Your comment captures the first three-quarters of the cycle correctly; the only thing missing is that it loops back to the starting value once radians reach `2π` (and then repeats indefinitely for larger inputs, or mirrors for negative inputs — both functions are periodic with period `2π`).

One nuance worth being aware of for anything geometry/rotation related: `cos` is just `sin` shifted by `π/2` — i.e. `cos(θ) = sin(θ + π/2)`. That's why they trace the same shape offset by a quarter turn, which is exactly what makes `(cos θ, sin θ)` trace a unit circle as θ increases — useful to keep in mind if you're using these for radial wall layouts, circular arrays, etc.
