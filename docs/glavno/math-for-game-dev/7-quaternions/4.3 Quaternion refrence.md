# Quaternion Reference

Notation: a quaternion is `q = (w, v)` where `w` is the scalar part and `v = (x, y, z)` is the vector part (the i, j, k coefficients).

```
q = w + x·i + y·j + z·k
```

## Multiplication

```
q1 * q2 = (w1·w2 − dot(v1, v2),  w1·v2 + w2·v1 + cross(v1, v2))
```

- Order matters: `q1 * q2 ≠ q2 * q1` (the cross product flips sign when swapped).
- Basic rules: `i² = j² = k² = −1`, `ij = k`, `jk = i`, `ki = j`, `ji = −k`, `kj = −i`, `ik = −j`.

Component form:

```
w = w1·w2 − x1·x2 − y1·y2 − z1·z2
x = w1·x2 + x1·w2 + y1·z2 − z1·y2
y = w1·y2 − x1·z2 + y1·w2 + z1·x2
z = w1·z2 + x1·y2 − y1·x2 + z1·w2
```

## Identity quaternion

```
q_id = (1, (0, 0, 0)) = 1 + 0i + 0j + 0k
```

- Means "no rotation".
- `q * q_id = q_id * q = q`

## Rotation quaternion

Rotation by angle `θ` around a **unit** axis `n = (nx, ny, nz)`:

```
q = (cos(θ/2), sin(θ/2) · n)

w = cos(θ/2)
x = sin(θ/2) · nx
y = sin(θ/2) · ny
z = sin(θ/2) · nz
```

- Must be unit length: `w² + x² + y² + z² = 1`
- Example, 90° around Y: `q = (0.7071, 0, 0.7071, 0)`
- Rotating a vector `p`: `p' = q * (0, p) * q⁻¹`, where `(0, p)` is `p` as a pure quaternion
- `q` and `−q` represent the same rotation
- Combining: `q_total = q2 * q1` means q1 is applied first, but this depends on the engine's convention, so check yours

### Reading a rotation quaternion

- The vector part `(x, y, z)` points along the rotation axis.
- `w = 1` means no rotation, `w = 0` means a 180° turn.
- The stored angle is half the real angle.

## Inverse quaternion

```
conjugate:  q* = (w, −v)
norm²:      |q|² = w² + x² + y² + z²
inverse:    q⁻¹ = q* / |q|²
```

For a **unit** quaternion (all rotation quaternions) this simplifies to:

```
q⁻¹ = q* = (w, −v)
```

- It rotates by `−θ` around the same axis, which undoes the rotation.
- `q * q⁻¹ = q⁻¹ * q = identity`
- Example: the inverse of `(0.7071, 0, 0.7071, 0)` is `(0.7071, 0, −0.7071, 0)`
- Inverse of a product reverses the order: `(q1 * q2)⁻¹ = q2⁻¹ * q1⁻¹`

### Why the inverse formula works

With `q1 = (w, v)` and `q2 = q* = (w, −v)`:

```
q * q* = w·w − dot(v, −v) + w(−v) + w·v + cross(v, −v)
       = w² + |v|² + 0 + 0
       = |q|²
```

The vector terms cancel and `cross(v, −v) = 0`, leaving a pure scalar. Dividing by `|q|²` gives 1, the identity.

## Practical reminders

1. Order of multiplication matters, and the meaning depends on the engine's convention.
2. Multiplying quaternions combines rotations.
3. Normalize occasionally to prevent floating-point drift.
