Yes, your reading is correct: **w is the scalar part, v is the (i, j, k) part**. They just renamed `a` to `w`. The step you're asking about isn't a calculation, only a change of letters.

## The renaming

| Your formula | Their notation |
| ------------ | -------------- |
| a1           | w1             |
| a2           | w2             |
| v1, v2       | v1, v2 (same)  |

So

```
q1q2 = a1a2 − dot(v1,v2) + a1·v2 + a2·v1 + cross(v1,v2)
```

becomes

```
q1q2 = w1·w2 − dot(v1,v2) + w1·v2 + w2·v1 + cross(v1,v2)
```

Note that `w1 * w1` in what you pasted is probably a typo (or a typo in the source). It should be `w1 * w2`, matching `a1a2`.

## Plugging in the identity

The identity quaternion is q1 = (v1, w1) = ((0,0,0), 1). Substitute into each term:

- `w1·w2` = 1·w2 = **w2**
- `dot(v1,v2)` = dot((0,0,0), v2) = **0**
- `w1·v2` = 1·v2 = **v2**
- `w2·v1` = w2·(0,0,0) = **0**
- `cross(v1,v2)` = cross((0,0,0), v2) = **0**

Sum:

```
q1q2 = w2 + v2 = q2
```

So `identity * q2 = q2`. Multiplying by the identity changes nothing, just like multiplying a number by 1. That's the whole point of their example: it's a sanity check that the formula behaves correctly, and it also shows why the identity is "no rotation".

## Quick check from the other side

If q2 is the identity (v2 = 0, w2 = 1), the terms give `w1 + v1 = q1`, so `q1 * identity = q1` as well. The identity works from both sides.
