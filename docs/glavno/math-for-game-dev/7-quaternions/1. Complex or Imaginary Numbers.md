#  `cos(θ) + sin(θ)i`  defines rotation

But what if we choose more less trivial numbers to multiply with, for example, lets multiply `3 + i` by `0.707 + 0.707i`

![[plottedcozsiz.excalidraw|700]]

So we end up calculating `1.414 + 2.828i` and we ploted it as you see above.

So point we started with `3 + i`, get transformed to mentioned point `1.414 + 2.828i` by multiplying with this complex number:  `0.707 + 0.707i`.

What is this  `0.707 + 0.707i` complex naumber? How did we pick him?

Well by looking at value 0.707, we can realize from many examples in many lessons before that this is cosinus or sinus of PI/4 radians or 45 degees.

So this imaginary number is Vector `(0.707, 0.707)` we can also plot.

![[plotingvectoronimaginary.excalidraw|700]]

So, this is what defines rotation:

```c
cos(θ) + sin(θ)i
```

We can use that general idea and we can exted the real numbers with these extra dimesions and define some rules and that helps us understand  how something like quaternions exist and how it makes rotation simpler in three dimensions.
