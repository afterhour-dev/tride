# Conversion

`360 degs = 2PI radians`  

`180 degs = PI radians`

```
radians = degrees * PI / 180
degrees = degrees * 180 / PI
```


![[2026-09-22_18-27.png]]


# Radians are  directly related to circumference of a unit circle

```ts
// let's try to get to it
// equation for circumference
circumference = 2 * r * PI

r = 1 // for unit circle

circumference = 2 * 1 * 3.14
circumference = 6.28 radians

// makes sense
```

Their unit is basically invented to relate arc lengths and angles using unit circle.
