- **θ** — the **angular coordinate**: the angle that line makes with the **positive `x`‑axis**, represented in radians

# Converting Vector from Cartesian coordinates representation to Polar coordinats representation

We have couple of ways of doing this.

Let's say we have direction vector represented wit cartesian coordinates: 
- `V = (0.707, 0.707)`

We want to represent the vector with polar coordinates, which means we need to find radial and angular coordinates

## Dot Product way

**We can do this by utalizing dot product**: [[3. Dot Product]]
$$
\begin{gather}
\vec{v}_{1} \cdot \vec{v_{2}} = |\lvert a\rvert| & |\lvert b\rvert| & \cos{\theta} 
\end{gather}
$$

### Finding radial coordinate - magnitude (we don't need to do this in unit vectors like ours but let's confirm it)

This is easy, radial coordinate is also magnitude of vector so we need to find magnitude

```ts
||v|| = sqrt(0.707*0.707 + 0.707*0.707)
||v|| = 0.999848988 ≈ 1

// Magnitude is indeed one
// we confirmed it
r = ||v|| = 1
```

### Calculating dot product from cartesian components

![[findingthetaforangularcoord.excalidraw|700]]
So , dot product is 0.707

### Finding the angular coordinate - angle theta (θ)

So we are using equation for dot product. once again but it's part to the right of =

```js

dot product = ||v1|| * ||v2|| * cos(θ) 

// we have calculated dot product, and we know all the magnitudes
0.707 = 1 * 1 * cos(θ)

cos(θ) = 0.707 

// Now we can use `θ = acos(cos(θ))`   to get an angular coordinate

```

# `acos` & `asin` or `ArcusCosinus` and `ArcusSinus`

In previous example we calculated what `cos` of `θ` is (`cos(θ)`), but how to get actual angle value from it.

We need to invert cosinus calculation to get original angle.

There are few functions we can invert cosine or sine calculation to get original angle:
- ArcusCosinus
- ArcusSinus
- ArcusTangens
![[2026-09-23_18-10.png]]

We need `acos` in this case and it is available in many programming languages.
I'll use javascript `Math.cos` to calculate the theta angle

```ts
cos(θ) = 0.707

// the way of doing it
θ = acos(cos(θ)) = acos(0.707)  

// getting it from javascript
Math.acos(0.707) = 0.7855491633997437
//

// our angle  
θ = 0.7855491633997437 radians

θ = 0.7855491633997437 * (180/PI) = 45.008651662838 deg ≈ 45 deg

```

# `atan2` - Fixing potential `cos/acos` and `sin/asin` problems we mentioned by using


They realized mentioned issues about sin and cos, in programming, 50 years ago, and introduced a new function: `atan2`.

![[2026-09-30_18-53.png]]

`atan2` arguments
- `y`
- `x` 
(Yes, in that order, first `y` and then `x`)
 
Wihich allows splitting circle into 4 quadrons, then map the result of atan call to the appropriate sections, giving you the angle theta without restrictions of `acos` or similar functions.

## Converting from Polar coordinates to Cartesian coordinates

We already saw how to convert cartesian to polar: [[3. Vector to Angle#Represent Cartesioan coordinates (x,y) in Polar coordinates (r,)]]
Let's now learn the oposite.

Let's say we have
- radial coordinate with value of 1 (we are doing this on unit circle)
- angular coordinate θ of some value (doesn't really matter which value)

We want to get cartesian `(x,y)`

Well, since our circle is unit circle:
- x component is the same as `cos(θ)`
- y component is the same as `sin(θ)`

![[polartocartesian.excalidraw|700]]

So how we transform polar coordinates to cartesian:

```ts
x = r * cos(θ);
y = r * sin(θ);
```
