# General definition of `sin` and `cos`

We are looking at triangle with `adjecent` (also called `base`) (_nalegla_) side, corresponding to `x` axes; and we have `opposite` (_naspramna_) side, corresponding to `y` axis. We also have `hypotenuse` corresponding to the unit Vector magnitude.

![[2026-09-22_19-53.png]]

# Triangle in unit circle

If we put our triagle into unit circle (or imagine we put it in) we can see that
- hypotenuse is 1
- we are deviding adjecent with 1 to get cosinus
- we are deviding opposite by 1 to get sinus
- sinus will be same as opposite side length
- cosinus will be same as adjecent side length

![[2026-09-22_20-21.png]]

Given that `hypotenuse` is actually a `magnitude` of the vector:
and since inside unit circle vector `adjecent` side is same as `x` component of the vector, and `opposite` side is same as component `y` of the vector, this is also true

```ts
a (x,y)

sin (θ) = a.x;
cos (θ) = a.y;
```

Using unit circle makes things simple and easy to understand; just remember than when we have unit size hypotenuse the divisions can be ignored, because we are dividing with length 1 of hypotenuse.

# Oscillations - `sin(θ) = cos(θ - π/2)`

Let's grow or progress the angle on a unit circle from 0 to 2PI and beyond.

![[oscilations.gif]]

![[2026-09-22_20-42.png]]

We ploted sin and cos on the unit circle, and  as you following circle you get oscilations. You get exact same curve for both, but with slight offset.

**Offset is exaclly `PI / 2` radians or 90deg**

So this is true.

`sin(θ) = cos(θ - PI/2)

You can notice this easily when angle is `90 deg` or `PI/2 radians`; at that angle; there you have 

`sin(PI/2) === cos(PI/2 - PI/2)`  ;      `sin(PI/2) === cos(0)`     ;     `1 === 1` 

**So they are same graph but shifted by `PI/2 radians`**.


# `tan` function

A bit odd but it is introduced in basic trigonometry.

And from what I remember, in triangle it is calculated like this:  `sin(θ) / cos(θ)`

It doesn't have super strong presence in game dev but we still want to understand it.

You can easily understand it from unit circle.

Like I said, it is `sin(θ) / cos(θ)` and it makes tangential line, but also a line that is parallel with y axis.

![[2026-09-22_23-53.png]]

But there is more, see this:
```ts
sin(θ) / cos(θ)    ===      opposite / hypotenuse / adjecent / hypotenuse
sin(θ) / cos(θ)    ===      opposite * hypotenuse / adjecent * hypotenuse
// we can cancel out hypotenuse on unit circle because it is equale to magnitude
// of 1 
sin(θ) / cos(θ)    ===      opposite / adjecent   
  
// 
```

Also It can be represented like this too. Well it is clear why is called tangents, it is tangential on the circle in above example or bellow.

![[2026-09-22_23-55.png]]

But first approach is better to use because that is the way you derive the value.

Also it is not possible for certain angles. If you guess `90deg` you are right.
```c
sin(PI/2) / cos(PI/2) = 1 / 0

1 / 0 === ♾️
```
