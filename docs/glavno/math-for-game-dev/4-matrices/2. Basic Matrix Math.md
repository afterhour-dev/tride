# Identity Matrix

Special **square matrix** with all ones (1) diagonaly, in a way that first element of first row needs to be 1 and last element of the lat row needs to be 1, and across diagonaly all elements need to be ones(1); and the all rest need to be zeroes (0).

![[2026-09-24_15-42.png]]

Let's try calculating this:

So that A matrix is called identity matrix

**Any time you multiply matrix by an identity matrix, you get same matrix**.

It's a matrix equivalent of multiplying number by 1. If you multiply x by 1, you get x back.

# Number of Columns of the matrix A must match number of Rows of matrix B in case of multiplication

Order matters.

**Number of columns of the first matrix must equal the number of rows of the second matrix**

So you can multiply matrices of different sizes together, being them squares or not, but number of columns of first must match the number of rows of second.

![[2026-09-24_15-46.png]]

on image above:
- numbers `n`, `m`, `p` describe numbers of rows and columns        
- `rows x columns`

And as you can see, the resulting matrix C will have
- same number of rows as matrix A
- same number of columns as matrix B.

It is interesting how in resulting matrix there is no `m` number; meaning C won't have number of columns as matrix A, and won't have number of rows as matrix B.

Let's do a quick example; Se wee have two matrices, 2x3 and 3x2 (number of columns match number of rows); meaning that resulting matrix will have 2 rows and 2 columns, a 2x2 matrix.

![[2026-09-24_15-52.png]]

This above is special matrix since number of columns will match the number of rows no matter you do AB or BA.

But, lets say for these matrices `A = 5x3`, `B=3x2`, what is only possible is `AB`. because in case `BA` number of columns of `B` wouldn't match number of rows of `A`.

# Vectors are n by 1 matrices

You can imagine Vectors as `n by 1` matrices in esence.

Meaning we represent Vectors as multiple number of rows and only one column: 
- `2x1`,
- `3x1`
- `4x1`

![[2026-09-24_16-36.png]]

| Vector       | Dimensions (rows × cols) | n   |
| ------------ | ------------------------ | --- |
| (x, y)       | 2 × 1                    | 2   |
| (x, y, z)    | 3 × 1                    | 3   |
| (x, y, z, w) | 4 × 1                    | 4   |

So the sentence "vectors are n by 1 matrices" is saying: a vector is a matrix with a variable number of rows (`n`, matching its dimensionality) and always exactly `1` column.
