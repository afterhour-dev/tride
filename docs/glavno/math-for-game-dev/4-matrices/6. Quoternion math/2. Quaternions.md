# Math and Quaternions


There is two basic ways of teaching math around quaternions.

The way of most game dev resources teach them is:
- Quaternions are these mathematical entities that exted idea of rotation from 3 dimension into fourth dimension.
	- They consist of imaginary Vector `(i j k)`, or three imaginary numbers
	- And they consist of one real number, a scalar
	
So imaginary vector of (ijk) with a scalar value. And these values have wiierd "rules" surrounding them in terms of multiplication.


![[2026-10-02_17-51.png]]

## "Rules" around multiplication

  $$
  i^{2} = j^{2} = k^{2} = ijk = -1
  $$
 
 And then you have this specific multiplication tables.
 ![[2026-10-02_16-47.png]]

For example (looking first at column and then row)  `ij` i equal to `k` 
or `ji` is equal to `-k`

# General representation of Quaternions

## Basic form

Generarly represented like this:

```c
a + bi + cj + dk
```

![[2026-10-02_18-11.png]]

So, the scalar value `a` plus sclar value `b` multiplied by `i`  plus scalar value `c` multiplied by `j` plus sclar value `d` multiplied by `k`

## As a Vector (x, y, z, w) in actual code

We store in four dimensional vector

```c
(b, c, d, a)
```

![[2026-10-02_18-16.png]]

So if three dimensional vector has components (x,y,z); then quaternion would be:
- `x, y, z,` - coeficients for imaginary  vector `ijk`
- `w` - scalar value

Again, pretty wierd. And pretty unintuitive

## As "Rotors"

There is a other way that teaches quaternions under a different name:
Quaternions as "rotors"

Matematiacllty the same thing but uses less know form of value called exterior algebra or Grassman algebra.

Requires knowing completely new operator called "exterior product"

General idea is that rotations don't happen around axis, instead they happen inside of plains. Which sort of have more intuitive sense.

It doesn't require another dimension for new axis to rotate around.

Like if you're thinking about 2D, a rotation in 2D requires you to rotate on an axis that doesn't exist in 2D.

In Craftsman algebra the rotations happen within the plain, not around an axis. The end result is really the same thing, but how you get there is slightly different. You also have slightly different fundamental building blocks. There's vectors, like we all know and love, but the exterior product of vectors gives you bivectors, which are formed from two vectors.

You could sort of think of these as plains, but with a specific orientation and magnitude. An interesting side note is that the cross product actually produces a bivector in exterior algebra, not a vector as in linear algebra. The coefficients are the same, but the interpretation, that's what's different.

Remember what I said that how you interpret things, like say a position versus a direction make all the difference? Yeah, so this is just another instance of that.

# What Quaternions give you

So what quaternions give you is the ability to rotate an object via a rotation axis and an angle. Or in rotor terms they interpret it as a rotation happening within the bivector specified by the vector part of the quaternion. Like I said, the math is the same, explanations are a bit different. For the purposes of this section we will stick with the original explanation. 

![[2026-10-02_20-14.png]]

So while with Euler angles we kind of rotate around each axis individually and with matrices you have to specify the linear transform in the form of basis vectors.
![[2026-10-02_20-15.png]]

Quaternions allow you to specify an axis that you are going to rotate around and an angle of how much you want to rotate. In that way it's not dissimilar to when we rotated around an axis using Euler angles or rotation matrices, except that this allows us to create an arbitrary axis and rotate around that instead.
![[2026-10-02_20-16.png]]


# Axis Angle

So to start, let's start with that very idea, the idea of having an **axis** and an **angle**. 

And this is a way of representing rotations called `Axis Angle`, and of course it consists of 
- a rotation 
- and a unit vector specifying the axis:
	- `n` and `θ` (theta). 

![[2026-10-02_20-30.png]]![[2026-10-02_20-30_1.png]]

And you can use the axis angle representation to do things like transforming vectors in much the same way that you would transform a vector with a matrix.

So to transform a vector by an axis angle rotation, there is something called 
- `Rodriguez's rotation formula`.
