# Rotation axis and an angle

So what quaternions give you is the ability to rotate an object via:
- rotation axis
and
- an angle. 

Or in rotor terms they interpret it as a rotation happening within the bivector specified by the vector part of the quaternion.

Like I said, the math is the same, explanations are a bit different. For the purposes of this section we will stick with the original explanation. 

![[2026-10-02_20-14.png]]

So while with Euler angles:
- we kind of rotate around each axis individually
And with matrices 
- you have to specify the linear transform, in the form of basis vectors.
![[2026-10-02_20-15.png]]

Quaternions allow you to specify:
- an axis that you are going to rotate around and an angle of how much you want to rotate. 
![[2026-10-02_20-16.png]]

In that way it's not dissimilar to when we rotated around an axis using Euler angles or rotation matrices, except that this allows us to create an arbitrary axis and rotate around that instead.

# Axis Angle

So to start, let's start with that very idea, the idea of having:
-  **axis**
and 
-  **angle**. 

And this is a way of representing rotations called `Axis Angle`, that consists of:
- unit vector `n` specifying the rotation axis
- `θ` (theta)  angle

![[2026-10-02_20-30.png]]![[2026-10-02_20-30_1.png]]

And you can use the axis angle representation to do things like transforming vectors in much the same way that you would transform a vector with a matrix.

# Rodrigues's rotation formula

# Downside of axis angle is interpolation 

And the other downside to `axis angle` is that while interpolation is possible, the results aren't perfect.

Watch as we see interpolation happen between these different methods and it's pretty clear that the quaternion based interpolation is just by far the winner here.
![[fourth.gif]]

If you smoothly blend between two vectors, watch what happens when we blend between these two vectors. Well you can clearly see that when they face away from each other like this, the interpolated versions in the middle, they get shortened.
![[lerp.gif]]

You can of course fix the problem by renormalizing the vectors. Notice how the angular velocity though, it isn't constant.
![[normalizeslerp.gif]]

You actually need to interpolate over the surface of the sphere that these points lie on, which is where quaternions really have the upper hand.
