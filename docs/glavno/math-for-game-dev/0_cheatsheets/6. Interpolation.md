
# LERP or Mix

- Getting Position in between two points A and B, given the fraction `t`
- I call t fraction, because it is a value between 0 and 1, and it is used to multiply the distance between B and A, in order to get partial of that distance
- Adding the partial of distance to the A will give actual position or point we are seeking between A and B 
```ts
P = A + t *(B - A)
// P is position

// or we can say

Position = minValue + fraction * (maxValue - minValue)

```

- I guess `t` is called `t` because most of the time, you will pass it a time related value, for example
```ts
t = elapsedTime / duration

// clearly duration / elapsed time will give you fractio nbetween 0 and 1
// representing the "percent" of duration
```


# Inverse LERP

- Getting the fraction for a given `Position` between `A` and `B`

```ts
t = (P - A) / (B - A)

// or we can say

fraction = (Position / minValue) / (maxValue - minValue)

```

# Remap

- mirroring some Position between A and B, to be position between C and D
- ofcourse you need to preserve proportion
- you need to
	- do `inverse LERP` for `A` and `B` to get fraction `t`
	- use fraction `t` in `LERP` of `C` and `D` to get position between them

```ts
// given      P   between     A        B
// find       P'  between     C        D

t = (P - A) / (B - A)

P' = C + t*(D - C)
```
