
# Radians and degrees

`360 degs = 2PI radians`  

`180 degs = PI radians`

```
radians = degrees * PI / 180
degrees = degrees * 180 / PI
```

##         2PI is circumference 
```ts
// let's try to get to it
// equation for circumference
circumference = 2 * r * PI

r = 1 // for unit circle

circumference = 2 * 1 * 3.14
circumference = 6.28 radians
```


# sin      cos
```ts
cos(θ) =  adjecent / hypotenuse 
sin(θ) = opposite / hypotenuse
```


# tan
```ts
tan(θ)   =      sin(θ) / cos(θ)    ===      opposite / adjecent 
```


# sin(θ) = cos(θ - π/2)
```ts
sin(θ) = cos(θ - π/2)
```


# Polar coordinates
```ts
(r, θ)

// r - radial
// θ - angular
```

##       cartesian to polar
```ts
// by utalizing dot product
// when you think about it
//   v1   is vector of the line making the angle θ
//   v2   is vector of angle zero, shares direction of positive x axis
v1.x * v2.x + v1.y * v2.y = ||v1|| * ||v2|| * cos(θ)

// by utalizing trigonometry
hypotenuse = ||v1||
adjecent = x
cos(θ) =     adjecent / hypotenuse =    x / ||v1||   

θ = acos(cos(θ))
r = ||v1|| 
```

##       polar to cartesian
```ts
x = r * cos(θ);
y = r * sin(θ);
```



# acos           asin

```ts
θ = acos(cos(θ))
θ = asin(sin(θ))
```


# Use `atan2` instead `acos` and `asin`

```ts
// y goes first
θ = atan2(y,x)

// where
y = r * sin(θ);
x = r * cos(θ);
// or cartesioan coordinates of the point
```

Result of `atan2` is in range between `-π` and `π`
