## Position Vector

In game development representation of a specific location in virtual space in the game world we use  these next terms interchangeably to refer to the same concept
- `Point` 
- `Position` 
 
And that concept is  `Position Vector` 

- often used interchangeably by gamedevs
- same idea
- underlying concept is the same

A `Position Vector` represent the point in the game World; representation of specific location in virtual space.
