
# Finding distance/length/magnitude

We use **PYTHAGOREAN THEOREM** to find distance; and distance is exactly the length of the direction vector or the magnitude of the direction vector. 

In programming we know about sqrt function so we can write it like this

$$
c = sqrt(x^2 + y^2)
$$


Or more correct depiction, where $$||\vec{v}||$$
is correct symbol for **length/distance/magnitude** we write like this
$$
||\vec{v}|| = \sqrt{ a^2 + b^2}
$$
where `a` is x element and b is `y` element of the vector.
