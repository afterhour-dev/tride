
Concept of operating with points and vectors in 2D is the same as in 1D, but math changes slightly.

If you want to make addition between Direction Vectors, or with Direction Vector and a Position Vector, you do it element wise, or component wise. Element-wise meaning by item inside parenthesis describing Vector or a Point.

So we can say that 2D Vector is the Vector with 2 elements, and 3D Vector would be Vector with 3 elements.
