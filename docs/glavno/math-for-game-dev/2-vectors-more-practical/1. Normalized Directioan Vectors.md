As we know, Points (PointVectors)  represent locations in space, and Vectors (Direction Vectors) represent direction and magnitude. Both represent numerical value but different concepts.

Direction Vector can be normalized. But what that means?

By my own words: We can say that normalization is the process of getting unit vector from our original vector, but preserving its direction.

And what is unit vector? Unit Vector is the direction vector which magnitude/length is exactly 1.

## What is a "normalized vector", or how do we normalize a vector

- Making his magnitude(length) being 1
- But preserving it's direction and sense(heading)

This is something that pops up all the time in game development especially in math:
- Position updates using spped + direction
- Physics simulations + collision detection
- Shaders, especially lighting
Mostly ensuring that callculations fall in a specific range.

## Normalizing - Dividing Vector by it's magnitude

We represent normalized vector as v with a hat
$$\hat{v}$$

This is the official equation: **normalized vector equals vector devided by its magnitude**
$$
 \hat{v} = \frac{\vec{v}}{\|\vec{v}\|}
$$

We would never have to do this by hand, except in some rare cases; because in threejs or in unity, or in shader language, you have dedicated methods for calculating unit vector, and they are called `normalize` or similar ``

## Math behind normalization is "proportion math"

given `OriginalVector` = (`element_1`, `element_2`)

Starting with Proportion:
`UnitVector / UnitVectotMagnitude` = `OriginalVector / OriginalVectorMagnitude`
`UnitVector / 1` = `OriginalVector / OriginalVectorMagnitude`

Now it is easy:
`UnitVector` = `OriginalVector / OriginalVectorMagnitude`

`UnitVector` = `(`
	`element_1`/ `OriginalVectorMagnitude` , 
	`element_2`/ `OriginalVectorMagnitude` 
 `)`

But you just should memorize that this is element-wise divison of vector by it's magnitude.

# Normalization is **Vector Scaling** by inverse of its magnitude

***Šta to konkretno znači?***

Kada normalizuješ vektor, radiš ovo:

$$\hat{v} = \frac{v}{|v|}$$

To jest — **deliš** vektor sa njegovom dužinom (magnitude). Ali deljenje sa brojem x je matematički isto što i **množenje sa 1/x** (recipročnom vrednošću tog broja):

$$\frac{v}{|v|} = v \times \frac{1}{|v|}$$

**A elemnt wise množenje Vektora jeste njegovo Scale-ovanje. Scale-ovanjem ćemo se baviti posebno u sledećoj lekciji.**

Dakle "**scale it by inverse of length**" = pomnoži svaku komponentu ili element vektora sa $\frac{1}{|v|}$, umesto da praviš deljenje.

Rezime:

| Termin                         | Značenje                                                                        |
| ------------------------------ | ------------------------------------------------------------------------------- |
| **length** (magnitude)         | $\|v\|$, dužina vektora                                                         |
| **inverse of length**          | $\frac{1}{\|v\|}$ — recipročna vrednost dužine                                  |
| **scale by inverse of length** | pomnoži vektor sa $\frac{1}{\|v\|}$ (matematički identično deljenju sa $\|v\|$) |

Znači, to je samo drugačiji način da se kaže "podeli sa dužinom" — ali izraženo kroz množenje, jer se tako brže izvršava u kodu.

To je pre svega **stilski/performansni** izbor u programiranju:

- Deljenje (`/`) je na procesoru **sporija** operacija od množenja (`*`).
- Ako imaš vektor sa 3 komponente (x, y, z), umesto da radiš 3 deljenja:

```
x/ magnitude       y/ magnitude         z/ magnitude 
```

izračunaš recipročnu vrednost **jednom**:

```
inverse = 1 / magnitude
```

pa onda samo množiš (3 množenja umesto 3 deljenja):

```
x * inverse           y * inverse         z *  inverse
```

Ovo je čest pattern u kodu za normalizaciju vektora (Unity, OpenGL shader-i, itd.) — recimo:

```csharp
float invLength = 1f / vector.magnitude;
Vector3 normalized = new Vector3(x * invLength, y * invLength, z * invLength);
```
