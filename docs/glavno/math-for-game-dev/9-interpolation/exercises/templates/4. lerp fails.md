# Where Lerp Fails

**1. Lerp assumes a linear relationship between the points it's interpolating between.**








**2. Cartesian space is linear.**








**3. You can safely interpolate scale using lerp.**








**4. Lerp is not suitable for interpolating between colours in RGB space.**








**5. Interpolating between unit vectors using lerp always produces accurate results.**








**6. Lerp can safely be used to interpolate rotation matrices.**








**7. Lerp results on unit vectors may produce vectors that aren't of unit length.**








**8. Renormalizing vectors after lerping can fix interpolation issues.**








**9. Interpolating in RGB space might introduce undesirable intermediary colours.**








**10. The purplish tint when lerping from yellow to blue in RGB space is an error from interpolation.**








**11. The error resulting from interpolation can sometimes be ignored in games.**








**12. Colours benefit from transformation to another space before interpolation.**
