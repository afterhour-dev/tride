# Transform Rotation

## Concept

### What is rotation

Every `Object3D` in Three.js has a `rotation` property. Unlike `position` (which is a `Vector3`), `rotation` is an **Euler** — a special class that represents rotation as three angles around the X, Y, and Z axes.

```ts
console.log(mesh.rotation); // Euler { _x: 0, _y: 0, _z: 0, _order: 'XYZ' }
```

An Euler is **not** a Vector3. It's a different class with its own behavior, especially around the order in which axes are applied.

### Radians, not degrees

Three.js uses **radians** for rotation, not degrees. The conversion is:

```
radians = degrees * Math.PI / 180
```

Common equivalents:

| Degrees | Radians | Approximate |
|---------|---------|-------------|
| 0°      | 0       | 0           |
| 45°     | π/4     | 0.785       |
| 90°     | π/2     | 1.571       |
| 180°    | π       | 3.142       |
| 360°    | 2π      | 6.283       |

To rotate 45 degrees around the Y axis:

```ts
mesh.rotation.y = Math.PI / 4;
```

### Rotating around axes

You set rotation the same way you set position — one axis at a time:

```ts
mesh.rotation.y = Math.PI / 4;  // 45° around Y
mesh.rotation.y += Math.PI / 4; // add another 45° → total 90°
```

### Gimbal lock

**Gimbal lock** happens when two axes of rotation align, causing you to lose a degree of freedom. With Three.js Euler rotation (default order `'XYZ'`), rotating 90° around the Y axis makes X and Z rotations behave identically — the object can no longer distinguish between them.

```ts
mesh.rotation.y = Math.PI / 2; // 90° around Y — gimbal lock!
```

At this point, rotating around X or Z produces the same visual result. This is a fundamental limitation of Euler angles, not a bug in Three.js.

### Reordering to fix gimbal lock

You can change the order in which Euler rotations are applied using `reorder()`:

```ts
mesh.rotation.reorder('YXZ');
```

This tells Three.js to apply Y rotation first, then X, then Z. Changing the order can avoid gimbal lock for certain rotation sequences. The default is `'XYZ'`. Other common orders are `'YZX'`, `'ZXY'`, `'ZYX'`, `'XZY'`, `'YXZ'`.

### Common rotation methods

Besides direct axis assignment, `Euler` offers:

- **`set(x, y, z, order?)`** — set all three angles at once
- **`reorder(order)`** — change the rotation order (e.g. `'YXZ'`)
- **`copy(euler)`** — copy values from another Euler
- **`setFromRotationMatrix(matrix)`** — derive rotation from a matrix

For most day-to-day work, you'll use direct axis assignment (`mesh.rotation.y = ...`). The `set()` method is handy when you want to set all three at once.

### Quaternions — the future

Quaternions avoid gimbal lock entirely and are the standard for animation and interpolation. This lesson doesn't cover them yet — they'll come in a future lesson when animation is introduced. For now, Euler angles are fine for static rotations.

## Code

in repo - `apps/2_transform_rotation`

```ts
import './style.css';
import * as THREE from 'three/webgpu';

import { getRequiredElement } from './util';

const canvas = getRequiredElement<HTMLCanvasElement>('canvas#tride');

const sizes = {
	width: 800,
	height: 600,
};

async function init() {
	const scene = new THREE.Scene();

	const boxGeometry = new THREE.BoxGeometry(0.5, 0.5, 0.5);
	const material = new THREE.MeshBasicMaterial({
		color: 0x4c9892,
		wireframe: true,
	});

	const mesh = new THREE.Mesh(boxGeometry, material);

	// --- Rotation transforms ---

	// Rotate 45° around Y axis
	mesh.rotation.y = Math.PI / 4;

	// Add another 45° → total 90° → gimbal lock
	mesh.rotation.y += Math.PI / 4;

	// Fix gimbal lock by changing rotation order
	mesh.rotation.reorder('YXZ');

	scene.add(mesh);

	// Camera
	const camera = new THREE.PerspectiveCamera(75, sizes.width / sizes.height);
	camera.position.z = 3;
	camera.position.y = 0.5;
	camera.position.x = 0.1;
	scene.add(camera);

	// Renderer
	const renderer = new THREE.WebGPURenderer({ canvas });
	await renderer.init();

	// Axes helper
	const axesHelper = new THREE.AxesHelper(5);
	axesHelper.setColors('red', 'green', 'blue');
	scene.add(axesHelper);

	renderer.setSize(sizes.width, sizes.height);
	renderer.setClearColor(0x000000, 1);
	renderer.render(scene, camera);
}

await init();
```

## Gotchas

- **Rotation is in radians, not degrees.** If you write `mesh.rotation.y = 90`, you're rotating 90 *radians* — which is about 5156°. Use `Math.PI / 2` for 90°.

- **Gimbal lock at 90°.** When `rotation.y` reaches π/2 (90°), rotations around X and Z become indistinguishable. This is visible in the app — the axes helper shows the effect. Use `reorder()` if you need to avoid it for specific rotation sequences.

- **Euler is not Vector3.** `mesh.rotation` is an `Euler`, not a `Vector3`. You can't call Vector3 methods like `length()` or `distanceTo()` on it. The assignment syntax looks the same, but the types are different.

### Roll Pitch Yaw

Yaw, pitch, and roll are the ==three primary dimensions of angular rotation defining an object's orientation in 3D space==.
- **Yaw** is side-to-side rotation (twisting around a vertical axis).

- **Pitch** is up-and-down movement (tilting around a side-to-side lateral axis).

- **Roll** is banking side-to-side (tilting around a front-to-back longitudinal axis)

Detailed Breakdown

These three rotational motions govern how objects—such as airplanes, drones, watercraft, and even animated 3D models—move through space across their six degrees of freedom. 

- **Yaw (Vertical Axis / Z-axis):** Refers to turning the nose of the vehicle left or right, much like shaking your head "no". In an aircraft, this is controlled by the rudder. 

- **Pitch (Lateral Axis / Y-axis):** Involves the nose of the vehicle pointing up or down, much like nodding your head "yes". In an aircraft, this movement is controlled by elevators on the tail.

- **Roll (Longitudinal Axis / X-axis):** The rotation of the vehicle around its front-to-back center, where one side dips while the other rises (banking). In an aircraft, this is controlled by ailerons on the wings.

Applications in Flight and Technology

Understanding these rotations is crucial for dynamic stabilization in aviation, rocketry, and modern robotics.
