## Concept

MeshToonMaterial is a non-photorealistic material that produces a flat, cartoon-like shading effect. Unlike realistic materials (PBR, Lambert, Phong), it doesn't aim for physical accuracy — it aims for a stylized look.

**Key characteristics:**

- **Requires light** — just like LambertMaterial and PhongMaterial, MeshToonMaterial needs light sources in the scene to be visible. Without lights, the object appears black.
- **Not realistic** — this material intentionally breaks away from physically accurate shading. If you're going for realism, this isn't the right choice. But if you're going for a cartoon, cel-shaded, or stylized aesthetic, it can look really cool.
- **Similar to Lambert in properties** — it responds to light in a comparable way (diffuse shading), but with a distinctive stepped/cel-shaded look instead of a smooth gradient.
- **Two-tone coloration by default** — by default, MeshToonMaterial splits the shading into two regions: a lit area and a shadow area. There's no smooth transition — it's an abrupt step, like classic cartoon shading.
- **Gradient map control** — the `gradientMap` property lets you override the default two-tone shading with a custom gradient texture. This is where things get interesting.

### The gradientMap and 3×1 textures

When you assign a small texture (like 3×1 pixels) to `gradientMap`, the GPU samples it based on how much light hits the surface. A 3×1 texture gives you three distinct shading bands instead of the default two — like a striped or stepped look.

Here's the catch: **the GPU naturally blends between pixels when sampling textures**. With a tiny 3×1 texture, the GPU interpolates between the three pixels, creating smooth gradients instead of sharp bands. That defeats the purpose of toon shading.

**The fix:**

```ts
gradientMap.minFilter = THREE.NearestFilter;
gradientMap.magFilter = THREE.NearestFilter;
gradientMap.generateMipmaps = false;
```

- **NearestFilter** — tells the GPU to pick the nearest pixel without any blending. No interpolation, no smoothing — just sharp transitions.
- **generateMipmaps = false** — mipmapping is the GPU creating smaller versions of the texture for distant objects. With a 3×1 texture, mipmaps would further blur the distinctions between pixels. Turning it off preserves the sharp bands.

Without these settings, your gradient texture won't produce the cartoon stripe effect you expect.

### Use case

MeshToonMaterial isn't widely used in professional production, but it's popular in indie games and stylized projects where a hand-drawn or cel-shaded look is desired.

## Code

in repo - `apps/10_7_MeshToonMaterial`

```ts
import * as THREE from 'three/webgpu';

// Load a gradient texture (3×1 or 5×1 pixel strip)
const gradientTexture = textureLoader.load('/gradients/5.jpg');

// CRITICAL: prevent GPU from blending pixels
gradientTexture.minFilter = THREE.NearestFilter;
gradientTexture.magFilter = THREE.NearestFilter;
gradientTexture.generateMipmaps = false;

const material = new THREE.MeshToonMaterial();
material.gradientMap = gradientTexture;

const mesh = new THREE.Mesh(geometry, material);
scene.add(mesh);

// Don't forget lights — MeshToonMaterial needs them
const ambientLight = new THREE.AmbientLight(0xffffff, 1);
const pointLight = new THREE.PointLight(0xffffff, 30);
scene.add(ambientLight, pointLight);
```

## Gotchas

- **Black objects without lights** — MeshToonMaterial requires light sources. If your object appears fully black, check that you've added at least an AmbientLight and/or a directional/point light.
- **Gradient texture looks smooth instead of banded** — you forgot to set `NearestFilter` and disable mipmapping. The GPU is interpolating between pixels, smoothing out the bands.
- **Two-tone vs. multi-tone** — the default (no `gradientMap`) gives you two bands. To get more bands (3, 5, etc.), use a gradient texture with the matching pixel width AND the NearestFilter settings.

## Revisit

- Experiment with different gradient texture sizes (2×1, 3×1, 5×1) to see how the number of shading bands changes.
- Compare MeshToonMaterial side-by-side with MeshLambertMaterial to see the difference between smooth and stepped shading.
- Look into custom shader-based toon shading for more control over the cel-shaded look.
