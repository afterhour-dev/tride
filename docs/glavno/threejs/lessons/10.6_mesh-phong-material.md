## Concept

`MeshPhongMaterial` is a material that simulates the **Phong shading model** — a classic lighting model that produces specular highlights on shiny surfaces. Unlike [[10.1_mesh-basic-material]] which ignores lights entirely, or [[10.2_mesh-normal-material]] which uses normals for color, MeshPhongMaterial **requires lights** in the scene to produce any visible output beyond a flat black silhouette.

### How Phong shading works

The Phong model breaks surface lighting into three components:

1. **Ambient** — a constant base light that ensures nothing is completely black. Provided by `AmbientLight` in Three.js.
2. **Diffuse** — light that scatters evenly across the surface based on the angle to the light source. This is the same Lambertian model used by [[10.5_mesh-lambert-material]].
3. **Specular** — the bright, focused highlight you see on shiny objects (a glass marble, a polished floor). This is what makes Phong different from Lambert.

The formula in simplified form:

$$
I = k_a \cdot I_a + k_d \cdot I_d \cdot \max(0, \vec{n} \cdot \vec{l}) + k_s \cdot I_s \cdot \max(0, \vec{r} \cdot \vec{v})^{\alpha}
$$

Where:
- $k_a$, $k_d$, $k_s$ are ambient, diffuse, and specular coefficients
- $\vec{n}$ is the surface normal, $\vec{l}$ is the light direction
- $\vec{r}$ is the reflected light vector, $\vec{v}$ is the view direction
- $\alpha$ is the shininess exponent — higher values produce tighter, sharper highlights

### Key properties

MeshPhongMaterial extends the base material with two distinctive properties:

- **`specular`** — a `THREE.Color` that controls the color of the specular highlight. By default it's a light gray (`0x111111`). Setting it to a colored value (like the purple `#a643c7` in the app) gives the highlight a tint — useful for simulating colored reflections on metals or plastics.
- **`shininess`** — a number (default `30`) that controls how concentrated the specular highlight is. Low values (e.g. `5`) produce wide, soft highlights (matte surfaces); high values (e.g. `100+`) produce tight, sharp highlights (polished or wet surfaces).

### Phong vs Lambert — when to use which

| | MeshLambertMaterial | MeshPhongMaterial |
|---|---|---|
| **Lighting model** | Diffuse only (Lambertian) | Diffuse + Specular (Phong) |
| **Needs lights** | Yes | Yes |
| **Specular highlights** | No | Yes |
| **Performance** | Faster | Slightly slower (specular calculation) |
| **Realistic?** | Basic diffuse shading | Better, but still not physically accurate |

MeshPhongMaterial sits in the middle of the Three.js material complexity spectrum: more capable than Lambert, but less physically accurate (and less expensive) than [[10.7_mesh-standard-material]] or [[10.8_mesh-physical-material]] which use PBR (physically-based rendering).

> **Note:** MeshPhongMaterial is **not** the same as the Phong shader in Blender. Three.js's implementation is a simplified version. For realistic results, prefer PBR materials (`MeshStandardMaterial` / `MeshPhysicalMaterial`).

## Code

in repo - `apps/10_6_Mesh_Phong_Material`

```ts
import * as THREE from 'three/webgpu';

// Phong material requires lights in the scene
const ambientLight = new THREE.AmbientLight(0xffffff, 1);
scene.add(ambientLight);

const pointLight = new THREE.PointLight(0xffffff, 30);
pointLight.position.set(2, 3, 4);
scene.add(pointLight);

// MeshPhongMaterial with specular and shininess
const material = new THREE.MeshPhongMaterial();
material.specular = new THREE.Color('#a643c7'); // purple specular highlight
material.shininess = 100; // tight, shiny highlight

const mesh = new THREE.Mesh(
  new THREE.SphereGeometry(0.5, 16, 16),
  material,
);
scene.add(mesh);
```

## Gotchas

- **Black silhouette without lights** — If you forget to add lights, MeshPhongMaterial renders as completely black. This is the most common gotcha when switching from MeshBasicMaterial or MeshMatcapMaterial.
- **Specular color is not the object color** — `specular` controls the highlight color, not the surface color. The surface color comes from `color` (default white). You can set both independently.
- **`shininess` vs `roughness`** — If you're coming from PBR materials (`MeshStandardMaterial`), note that Phong uses `shininess` (higher = shinier) while PBR uses `roughness` (lower = shinier). They're inversely related concepts.

## Revisit

- Phong is a good stepping stone to understanding PBR materials. Once you're comfortable with Phong's specular/shininess model, the jump to `MeshStandardMaterial`'s metalness/roughness workflow makes more sense.
- Consider experimenting with different `specular` colors to see how colored highlights affect the perceived material (e.g. gold = warm specular, chrome = white specular).

## Outdated

MeshPhongMaterial is **not outdated** — it's still a valid, lightweight material for scenes where physically-based rendering isn't necessary. However, for most production work, `MeshStandardMaterial` or `MeshPhysicalMaterial` are preferred because they produce more realistic results with less manual tweaking.

> 💡 More up to date alternative: `MeshStandardMaterial` uses PBR (physically-based rendering) with metalness/roughness parameters that are more intuitive and produce more realistic results by default — see the Three.js docs for [MeshStandardMaterial](https://threejs.org/docs/#api/en/materials/MeshStandardMaterial).
