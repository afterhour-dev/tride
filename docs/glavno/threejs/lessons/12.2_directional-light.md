# 12.2 Directional Light

## Concept

Directional light simulates a **sun-like** effect — all light rays travel in parallel, as if coming from an infinitely distant source (like the Sun). Unlike point light (which emits from a single point in all directions), directional light hits every object in the scene from the same angle, regardless of where the object is.

### Creating a Directional Light

```ts
const light = new THREE.DirectionalLight(0xffffff, 0.8)
```

The constructor takes two arguments:

1. **color** — the light color (default: `0xffffff`)
2. **intensity** — brightness multiplier (default: `1`)

You can also set these after creation:

```ts
light.color.set(0xffffff)
light.intensity = 0.8
```

### Position and Direction

![[directional.png]]

This is a key concept to understand: **DirectionalLight has a position, but it doesn't behave like a point light at that position**. The position determines the **direction** from which light rays come — not where the light source physically is.

By default, position is `(0, 1, 0)` — that's why in the app the light appears to come from above, illuminating the top hemisphere of the sphere but leaving the bottom dark.

When you change the position (e.g., to `(5, 5, 5)`), the light rays now come from that direction at an angle, which is visible on the sphere as a shift in the bright area.

### Why Distance Doesn't Matter (Yet)

The `distance` property of DirectionalLight isn't meaningful right now — it will matter when we get to **shadows** in a later lesson. For now, you can safely ignore it.

### ArrowHelper — Visualizing Light Direction

The app uses `THREE.ArrowHelper` to draw an arrow showing the light's direction:

```ts
const arrowHelper = new THREE.ArrowHelper(
  light.position.clone().normalize(), // direction
  new THREE.Vector3(0, 0, 0),         // origin
  1,                                  // length
  0xffffff                            // color
)

scene.add(arrowHelper);

```

This is a useful debug technique — you can see exactly where the light is coming from in the scene.

### DirectionalLightHelper

To visualize light

```ts
const directionalLightHelper = new THREE.DirectionalLightHelper(
  directionalLight,
  5,
);
scene.add(directionalLightHelper);
```

arrowHelper shows us from which direction light is comming, and this helper shows us direction of the light from the source, so it is other way around.

**In app we added both helpers to the gui.**

### MeshBasicMaterial and Light Interaction

`MeshBasicMaterial`. This material is **not affected by lights** 

To see directional light properly,use something like `MeshStandardMaterial` or `MeshPhongMaterial` — these react to light sources and show proper shading.

## Code

in repo - `apps/12_2_directional_light`

```ts
import './style.css'
import * as THREE from 'three'
import { OrbitControls } from 'three/examples/jsm/controls/OrbitControls.js'
import { GUI } from 'lil-gui'

const scene = new THREE.Scene()
const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 1000)
camera.position.z = 3

const renderer = new THREE.WebGLRenderer({ antialias: true })
renderer.setSize(window.innerWidth, window.innerHeight)
document.body.appendChild(renderer.domElement)

// Ambient light — provides base illumination
const ambientLight = new THREE.AmbientLight(0xffffff, 0.1)
scene.add(ambientLight)

// Directional light — sun-like, parallel rays
const directionalLight = new THREE.DirectionalLight(0xffffff, 0.8)
directionalLight.position.set(5, 5, 5)
scene.add(directionalLight)

// Arrow helper — shows direction of light
const arrow = new THREE.ArrowHelper(
  directionalLight.position.clone().normalize(),
  new THREE.Vector3(0, 0, 0),
  1,
  0xffffff
)
scene.add(arrow)

// MeshBasicMaterial sphere — NOT affected by directional light
const sphere = new THREE.Mesh(
  new THREE.SphereGeometry(1, 64, 64),
  new THREE.MeshBasicMaterial({ color: 0x00ff00 })
)
scene.add(sphere)

// GUI
const gui = new GUI()
gui.add(directionalLight, 'intensity', 0, 1, 0.01)
gui.add(directionalLight.position, 'x', -5, 5)
gui.add(directionalLight.position, 'y', -5, 5)
gui.add(directionalLight.position, 'z', -5, 5)
gui.add(ambientLight, 'intensity', 0, 1, 0.01)

const controls = new OrbitControls(camera, renderer.domElement)

function animate() {
  requestAnimationFrame(animate)
  arrow.setDirection(directionalLight.position.clone().normalize())
  renderer.render(scene, camera)
}
animate()

window.addEventListener('resize', () => {
  camera.aspect = window.innerWidth / window.innerHeight
  camera.updateProjectionMatrix()
  renderer.setSize(window.innerWidth, window.innerHeight)
})
```

## Gotchas

- If for example **Sphere appears dark despite having directional light**: maybe you have `MeshBasicMaterial` that does **not** react to lights. It renders a flat uniform color. Use `MeshStandardMaterial` or `MeshPhongMaterial` to see proper lighting effects.

- **Directional light position (0, 1, 0) vs point light**: Position on a directional light defines **direction**, not the light source's location. Don't confuse this with point light, where position is where light originates.

- **Forgot to add color/intensity in constructor args**: If you create `new THREE.DirectionalLight()` without arguments, color defaults to white (0xffffff) and intensity to 1. If you want to set them later via GUI, this works, but it's cleaner to pass them in the constructor:

```ts
// Preferred
const light = new THREE.DirectionalLight(0xffffff, 0.8)

// Also works but less clean
const light = new THREE.DirectionalLight()
light.intensity = 0.8
```
