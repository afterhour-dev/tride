## Concept

Textures in Three.js can be transformed directly through their properties — repeat, offset, rotation, and center. These transformations let you tile, shift, spin, and reposition how a texture appears on a surface without touching the geometry.

The app demonstrates these properties on a `Texture` object loaded from a PBR texture set (wooden door). All transformation properties live directly on the texture instance, not on the material or mesh.

### Repeat

The `repeat` property is a `Vector2` that controls how many times the texture tiles across the surface. By default, a texture does not repeat — the last pixel is stretched to fill the remaining area. To enable tiling, set the wrapping mode:

- `texture.wrapS = THREE.RepeatWrapping` — horizontal wrapping
- `texture.wrapT = THREE.RepeatWrapping` — vertical wrapping

The `S` and `T` naming comes from OpenGL convention (texture coordinates U/V map to S/T in wrapping). `S` is the horizontal axis, `T` is the vertical axis.

For mirrored tiling, use `THREE.MirroredRepeatWrapping` — the texture flips back and forth like a mirror at each tile boundary.

### Offset

The `offset` property is also a `Vector2`. Shifting `x` and `y` values moves the texture across the surface — positive `x` moves it right, positive `y` moves it up.

### Rotation

The `rotation` property takes a value in radians. Rotating a texture spins it around its `center` point. Without setting `center`, rotation happens around the corner (origin) of the UV space, which often looks wrong.

### Center

The `center` property is a `Vector2` that defines the pivot point for rotation. Setting it to `(0.5, 0.5)` puts the rotation center at the middle of the texture, which is usually what you want. The values are in UV space (0 to 1), not pixels.

## Code

in repo - `apps/8_texture_transforming`

```ts
// Repeat — tile the texture 2×3
colorMap.repeat.x = 2;
colorMap.repeat.y = 3;
colorMap.wrapS = THREE.RepeatWrapping;
colorMap.wrapT = THREE.RepeatWrapping;

// Offset — shift the texture
colorMap.offset.x = 0.5;
colorMap.offset.y = 0.5;

// Rotation — spin 45° (π/4 radians)
colorMap.rotation = Math.PI * 0.25;

// Center — pivot rotation around the middle
colorMap.center.x = 0.5;
colorMap.center.y = 0.5;
```

## Gotchas

- **Rotation without center set** — the texture rotates around the corner (UV origin), which looks unexpected. Always set `center` to `(0.5, 0.5)` before rotating.
- **Repeat without RepeatWrapping** — setting `repeat` without enabling `wrapS`/`wrapT` does nothing visible. The texture stays stretched.
- **Order of operations** — rotation happens after offset and repeat. Changing rotation after offset can produce surprising results.
- **MeshBasicMaterial vs MeshStandardMaterial** — repeat/offset/rotation work with any material, but PBR maps (normal, roughness, etc.) may need their own transformations. This app only transforms the color map.

## Revisit

- Try applying different transformations to each PBR map (normal, roughness, metallic) to see how they combine.
- Experiment with `MirroredRepeatWrapping` vs `RepeatWrapping` on the same repeat values — compare the seam artifacts.
- Check how these transforms interact with UV mapping on non-box geometries (sphere, torus).
