# 10.3 MeshMatcapMaterial

## Concept

`MeshMatcapMaterial` is a performance-friendly material that creates the illusion of lighting and shading using a single texture lookup, rather than computing actual lighting. It reads colors from a "matcap" (material capture) texture based on the surface normal orientation relative to the camera.

### How it works

1. You provide a texture that looks like a lit sphere — this is your matcap.
2. For each pixel on the mesh, Three.js looks at the surface normal direction relative to the camera.
3. It uses that direction to sample a color from the matcap texture.
4. The result looks like the mesh is lit, but it's actually just an illusion baked into the texture.

This means:
- **Very fast** — no light calculations needed, just a texture lookup
- **No lights needed** — the scene doesn't require any light sources
- **Limitation** — the "lighting" is baked and doesn't change when you move the camera or rotate the object (the shading stays fixed relative to the camera)

### Matcap texture sources

You can get matcap textures from:
- [matcaps collection on GitHub](https://github.com/nidorx/matcaps) — large library, but check licenses for commercial use
- Create your own in 3D software (Blender, etc.) by rendering a sphere
- Use 2D software like Photoshop
- Online tools like [MatCap Studio](https://kchplr.eu/matcap-studio/) — lets you interactively design matcaps

### Setting the matcap

You can set the matcap texture either:
- When instantiating: `new THREE.MeshMatcapMaterial({ matcap: texture })`
- After instantiation: `material.matcap = texture`

Both approaches work — setting it after instantiation gives you more flexibility for hot-swapping textures.

## Code

in repo - `apps/10_3_MeshMatcapMaterial`

```ts
import * as THREE from 'three/webgpu';

const textureLoader = new THREE.TextureLoader();

// Load a matcap texture (sphere-shaped image)
const matcapTexture = textureLoader.load('/matcaps/8.png');
matcapTexture.colorSpace = THREE.SRGBColorSpace;

// Create the material
const material = new THREE.MeshMatcapMaterial({
  // matcap: matcapTexture  // can also set here
});

// Or set after instantiation
material.matcap = matcapTexture;

// Apply to any mesh — no lights needed!
const sphere = new THREE.Mesh(
  new THREE.SphereGeometry(0.5, 16, 16),
  material
);
```

## Gotchas

- **No dynamic lighting** — the matcap shading is baked. Moving the camera or rotating the object won't change how light appears to hit it. If you need real-time lighting, use `MeshStandardMaterial` or `MeshPhysicalMaterial` instead.
- **Color space matters** — set `matcapTexture.colorSpace = THREE.SRGBColorSpace` or colors will look washed out.
- **Matcap must look like a sphere** — the texture should depict a sphere lit from a consistent direction. Random images won't produce good results.

## Revisit

- Try different matcap textures to see how they change the look of the same geometry
- Compare performance with `MeshStandardMaterial` in scenes with many objects
- Experiment with creating your own matcap in Blender or an online tool
