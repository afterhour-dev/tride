# Transform Position

## Concept

### Object3D and its role in Three.js

Everything visible in a Three.js scene inherits from `Object3D`. A `Mesh` is an `Object3D`. A `Camera` is an `Object3D`. An `AxesHelper` is an `Object3D`. This shared base class is what gives every object in the scene a `position`, `rotation`, and `scale` — the three fundamental transforms.

In this app, three things are `Object3D` instances:
- `mesh` (a `Mesh`, which is also a `BufferGeometry` + `Material`)
- `camera` (a `PerspectiveCamera`)
- `axesHelper` (an `AxesHelper`)

### What is position

Every `Object3D` has a `position` property. This is a `Vector3` — a 3-component vector representing the object's location in world space along the X, Y, and Z axes.

```ts
mesh.position.x = 0.7;
mesh.position.z = -1;
mesh.position.y = 1;
```

The position starts at `(0, 0, 0)` — the center of the scene (the "origin"). Moving it changes where the object appears.

### What is Vector3

`mesh.position` is an instance of `THREE.Vector3`. You can verify this:

```ts
console.log(mesh.position instanceof THREE.Vector3); // true
```

A `Vector3` holds three numbers: `x`, `y`, and `z`. It represents a point in 3D space or a direction. The same class is used for positions, directions, velocities, colors (with 3 channels), and more.

### Useful Vector3 methods

**`length()`** — returns the distance from the origin `(0, 0, 0)` to this vector. Mathematically, it's `sqrt(x² + y² + z²)`:

```ts
console.log(mesh.position.length()); // distance from center of scene
```

**`distanceTo(otherVector)`** — returns the distance between two vectors:

```ts
console.log(mesh.position.distanceTo(new THREE.Vector3(5, 5, 5)));
```

**`normalize()`** — scales the vector so its length becomes `1`, while preserving direction. This is useful when you care about direction but not magnitude:

```ts
mesh.position.normalize();
console.log(mesh.position.length()); // always 1
```

Think of it as sliding the point along a line from the origin through the vector until it's exactly 1 unit away from the center.

### Setting position values

**Direct assignment** — the most straightforward way:

```ts
mesh.position.x = 0.8;
mesh.position.z = 0.5;
mesh.position.y = -0.2;
```

**Arithmetic with existing values** — since position is a regular object with `x`, `y`, `z` properties, you can read and write them:

```ts
mesh.position.x -= 0.1; // subtract 0.1 from current x
```

**`setX()` / `setY()` / `setZ()`** — methods that set a single axis:

```ts
mesh.position.setX(0.6);
mesh.position.setX(mesh.position.x + 0.1);
```

These are functionally identical to direct assignment (`mesh.position.x = 0.6`). The main reason to use them is chainability — `setX` returns `this`, so you can write `mesh.position.setX(1).setY(2)`.

**`set(x, y, z)`** — sets all three components at once. You can omit `z` (defaults to current z):

```ts
mesh.position.set(1, 1);      // x=1, y=1, z stays as is
mesh.position.set(0.9, -0.3, 1.2); // all three set
```

You **cannot** set only `x` with `set()` — it requires at least two arguments.

## Code

in repo - `apps/2_transform_position`

```ts
import './style.css';
import * as THREE from 'three/webgpu';

import { getRequiredElement } from './util';

const canvas = getRequiredElement<HTMLCanvasElement>('canvas#tride');

const sizes = {
	width: 800,
	height: 600,
};

async function init() {
	const scene = new THREE.Scene();

	const boxGeometry = new THREE.BoxGeometry(0.5, 0.5, 0.5);
	const material = new THREE.MeshBasicMaterial({
		color: 0x4c9892,
		wireframe: true,
	});

	const mesh = new THREE.Mesh(boxGeometry, material);

	// --- Position transforms ---

	mesh.position.x = 0.7;
	mesh.position.z = -1;
	mesh.position.y = 1;

	console.log(mesh.position);              // Vector3 { x: 0.7, y: 1, z: -1 }
	console.log(mesh.position instanceof THREE.Vector3); // true
	console.log(mesh.position.length());     // distance from origin

	mesh.position.normalize();
	console.log(mesh.position.length());     // now 1

	// Setting values
	mesh.position.x = 0.8;
	mesh.position.z = 0.5;
	mesh.position.y = -0.2;
	mesh.position.x -= 0.1;                 // arithmetic

	mesh.position.setX(0.6);                // setX method
	mesh.position.set(0.9, -0.3, 1.2);     // set all at once

	scene.add(mesh);

	// Camera — also an Object3D with position
	const camera = new THREE.PerspectiveCamera(75, sizes.width / sizes.height);
	camera.position.z = 3;
	camera.position.y = 0.5;
	camera.position.x = 0.1;
	scene.add(camera);

	// Renderer
	const renderer = new THREE.WebGPURenderer({ canvas });
	await renderer.init();

	// Axes helper for visual reference
	const axesHelper = new THREE.AxesHelper(5);
	axesHelper.setColors('red', 'green', 'blue');
	scene.add(axesHelper);

	renderer.setSize(sizes.width, sizes.height);
	renderer.setClearColor(0x000000, 1);
	renderer.render(scene, camera);
}

await init();
```

## Gotchas

- **Position assignment is not stateful.** Writing `mesh.position.x = 0.8` replaces the previous value entirely. It does not add to it. If you want to increment, use `mesh.position.x += 0.1` or `mesh.position.x -= 0.1`.

- **`set()` requires at least two arguments.** You cannot call `mesh.position.set(1)` — it expects `set(x, y)` or `set(x, y, z)`. To set only one axis, use `setX()`, `setY()`, or `setZ()`, or assign directly.

- **Camera defaults matter.** A `PerspectiveCamera` starts at `(0, 0, 0)` looking down the negative Z axis. If you don't move it back (`camera.position.z = 3`), you'll be inside the mesh and see nothing.

## Revisit

- The full `Vector3` API — `add()`, `sub()`, `multiplyScalar()`, `lerp()`, `cross()`, `dot()` — will become important when working with rotations, directions, and physics. Revisit once you start moving objects through space rather than just positioning them statically.
- The relationship between `Object3D.position` and the object's local vs. world coordinate system (especially once parent-child hierarchies are introduced).
