## Concept

`lil-gui` is a lightweight GUI library for creating debug panels in Three.js projects. It lets you expose scene properties as interactive controls — sliders, color pickers, checkboxes, dropdowns, and buttons — so you can tweak values in real time without editing code.

### GUI Constructor Settings

When creating a `GUI` instance, you can pass an options object:

```ts
const gui = new GUI({
  width: 350,         // panel width in pixels
  title: 'Nice debug UI', // title shown at top
  closeFolders: true,  // folders start collapsed
});
```

### Adding Tweaks

Basic tweak — bind any object property:

```ts
gui.add(object, 'propertyName');
```

With range constraints:

```ts
gui.add(object, 'propertyName')
  .min(-3)
  .max(3)
  .step(0.01);
```

Rename the tweak label:

```ts
gui.add(object, 'propertyName').name('Custom Label');
```

### Tweak Types

| Type | Method | Use Case |
|---|---|---|
| Number slider | `.add(obj, prop).min().max().step()` | Continuous values (position, speed) |
| Color picker | `.addColor(obj, prop)` | Color values (hex strings, `THREE.Color`) |
| Boolean toggle | `.add(obj, prop)` | Visibility, wireframe on/off |
| Function button | `.add(obj, prop)` | Trigger actions (spin, reset) |
| Dropdown | `.add(obj, prop, { label: value })` | Enum-style choices |

### Callbacks

- `.onChange(fn)` — fires on every value change (drag, input)
- `.onFinishChange(fn)` — fires only when the user releases the control (use for expensive operations like rebuilding geometry)

### Folders

Group related tweaks:

```ts
const folder = gui.addFolder('My Group');
folder.add(obj, 'prop');
folder.close(); // start collapsed
```

### Keyboard Toggle

Hide/show the GUI panel with a keypress:

```ts
window.addEventListener('keydown', (ev) => {
  if (ev.key === 'h') {
    gui.show(gui._hidden); // toggle visibility
  }
});
```

> ⚠️ `gui._hidden` is an internal property — it works but may break in future lil-gui versions.

## Code

in repo - `apps/7_gui_parameters`

```ts
import GUI from 'lil-gui';

const gui = new GUI({ width: 350, title: 'Nice debug UI', closeFolders: true });

const folder = gui.addFolder('Awesome cube');
folder.close();

// Number slider with range
folder.add(mesh.position, 'y').min(-3).max(3).step(0.01);

// Color picker
folder.addColor(debugObject, 'color').onChange((color) => {
  material.color.set(color);
});

// Boolean toggle
folder.add(mesh, 'visible').name('mesh visible');

// Function button
folder.add(debugObject, 'spin');

// Dropdown
folder.add(debugObject, 'speed', { slow: 2, fast: 8 });

// Expensive operation — use onFinishChange
folder.add(debugObject, 'subdivisions')
  .min(1).max(20).step(1)
  .onFinishChange((subdivs) => {
    geometry.dispose();
    mesh.geometry = new THREE.BoxGeometry(1, 1, 1, subdivs, subdivs, subdivs);
  });
```

## Gotchas

- **`onChange` vs `onFinishChange`**: `onChange` fires on every tiny movement during a drag — don't use it for expensive operations like rebuilding geometry or disposing resources. Use `onFinishChange` for those.
- **`gui._hidden` is private**: Toggling visibility with `gui.show(gui._hidden)` works but relies on an internal property that could change between lil-gui versions.
- **Dispose old geometry before creating new**: When rebuilding geometry from a tweak callback, always call `.dispose()` on the old geometry first to avoid GPU memory leaks.
- **Dropdown values are not reactive**: Changing a property in code after creating a dropdown tweak won't update the GUI display — the GUI only reflects user interaction, not programmatic changes.
