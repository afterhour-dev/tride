# MeshPhysicalMaterial

`MeshPhysicalMaterial` extends `MeshStandardMaterial` with support for advanced physical effects. It inherits all standard material properties (map, normalMap, metalness, roughness, etc.) and adds four extra effect groups: **clearcoat**, **sheen**, **iridescence**, and **transmission**. Because of these additional calculations, it is the most expensive material in Three.js in terms of performance — use it only when you actually need one of these effects.

## Concept

### Clearcoat

Simulates a thin layer of varnish on top of the base material. It has its own reflective properties — you can see a shiny coating on the surface while the underlying material is still visible underneath.

- `clearcoat` (0–1) — intensity of the clear coat layer. Set to 1 for full varnish effect, 0 to disable.
- `clearcoatRoughness` (0–1) — how rough the clear coat is. 0 = perfectly smooth mirror-like coat, 1 = fully diffuse.

### Sheen

Highlights the material when viewed from a narrow angle. Typically used for fluffy or fuzzy materials like fabric, velvet, or suede.

- `sheen` (0–2) — intensity of the sheen effect.
- `sheenRoughness` (0–2) — how spread out the sheen highlight is.
- `sheenColor` — color of the sheen highlight (use `addColor` in lil-gui to tweak it).

### Iridescence

Creates color artifacts that shift based on viewing angle, similar to a fuel puddle, soap bubble, or the surface of a LaserDisc.

- `iridescence` (0–1) — intensity of the iridescence effect.
- `iridescenceIOR` (0–2.333) — index of refraction for the iridescent layer. Controls how the color shift behaves.
- `iridescenceThicknessRange` — a `[min, max]` array (in nanometers) that defines the thickness range of the thin film. Thicker values produce more dramatic color shifts.

### Transmission

Enables light to pass through the material, creating a translucent glass-like effect. This is more than just transparency with `opacity` — the image behind the object gets **deformed** by refraction, which makes the material feel physically present rather than just see-through.

- `transmission` (0–1) — how much light passes through. 1 = fully transmissive.
- `ior` — Index of Refraction. Depends on the material you're simulating:
  - Diamond: 2.417
  - Water: 1.333
  - Air: 1.000293
- `thickness` — a fixed value representing the object's thickness. The actual geometry thickness is **not** taken into account — this is a visual approximation.

> See the full list of IOR values at [Wikipedia — List of refractive indices](https://en.wikipedia.org/wiki/List_of_refractive_indices).

### Performance

`MeshPhysicalMaterial` is the worst material in terms of performance among all built-in Three.js materials. For many projects, `MeshStandardMaterial` is sufficient — only reach for physical when you specifically need clearcoat, sheen, iridescence, or transmission.

### Inheritance

All `MeshStandardMaterial` properties still work because `MeshPhysicalMaterial` extends it. In the app, the door textures (albedo, AO, displacement, metalness, roughness, normal, alpha) are set up the same way as in the standard material lessons.

## Code

in repo - `apps/10_11_MeshPhysicalMaterial`

```ts
import * as THREE from 'three/webgpu';

const material = new THREE.MeshPhysicalMaterial();

// Standard properties (inherited from MeshStandardMaterial)
material.map = doorAlbedoTexture;
material.aoMap = doorAmbientOcclusionTexture;
material.aoMapIntensity = 1;
material.displacementMap = doorHeightTexture;
material.displacementScale = 0.08;
material.metalnessMap = doorMetalnessTexture;
material.roughnessMap = doorRoughnessTexture;
material.normalMap = doorNormalTexture;
material.normalScale.set(0.5, 0.5);
material.transparent = true;
material.alphaMap = doorAlphaTexture;

// Clearcoat
material.clearcoat = 1;
material.clearcoatRoughness = 0;

// Sheen
material.sheen = 1;
material.sheenRoughness = 0.25;
material.sheenColor.set(1, 1, 1);

// Iridescence
material.iridescence = 1;
material.iridescenceIOR = 1;
material.iridescenceThicknessRange = [100, 800];

// Transmission
material.transmission = 1;
material.ior = 1.5;
material.thickness = 0.5;
material.metalness = 0;   // must be 0 for transmission to look right
material.roughness = 0;   // must be 0 for transmission to look right
```

## Gotchas

- **Transmission requires `metalness = 0` and `roughness = 0`.** If either is above 0, the transmissive effect won't look correct — the material will appear dark or distorted in unexpected ways. This is the single most common mistake when working with transmission.
- **When experimenting with transmission, comment out the texture-related properties** (`map`, `aoMap`, `displacementMap`, etc.) from the material. They interfere with the transmissive look and make it hard to see what's actually happening.
- **Effects don't stack cleanly.** If you enable sheen, iridescence, and transmission all at once, the result can be hard to read. Tweak one effect at a time and disable the others to understand what each one does.
- **`thickness` is a lie.** It's a fixed visual value, not based on actual geometry. A thin plane with `thickness = 1` will look the same as a thick box with `thickness = 1`.
- **`ior` range in the GUI goes to 10**, but realistic values are usually between 1.0 and 2.5. Going above that produces unrealistic results (useful for artistic effects though).
