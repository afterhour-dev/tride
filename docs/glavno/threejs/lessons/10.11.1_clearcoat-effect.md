# 10.11.1 clearcoat-effect

## Concept

The clearcoat effect in Three.js's `MeshPhysicalMaterial` simulates a thin layer of varnish or clear coat applied on top of the base material. This creates a two-layer material system where:

1. **Base layer**: The underlying material (wood, metal, plastic, etc.) with its own color, roughness, and metalness
2. **Clear coat layer**: A transparent, glossy layer on top that has its own reflective properties

The clearcoat layer acts like a separate reflective surface - it has its own roughness and reflectivity while still allowing you to see the base material beneath it. This is perfect for simulating:
- Varnished wood (like a wooden door with a glossy finish)
- Car paint with clear coat
- Polished furniture
- Any surface with a glossy protective coating

### Key Properties

- **`clearcoat`**: Controls the intensity of the clearcoat effect (0-1). At 1, you get a full, prominent clearcoat layer. At 0, it's invisible.
- **`clearcoatRoughness`**: Controls how rough or smooth the clearcoat layer is. At 0, it's perfectly smooth and mirror-like. At 1, it's very diffuse.

### Setting Metalness and Roughness for Clearcoat

When using clearcoat with a texture like a wooden door, you need to consider what the texture represents:
- **Metalness**: Should typically be low (0-0.3) for non-metallic materials like wood. High metalness values (1.0) make the entire surface look metallic, which may not be realistic for wood.
- **Roughness**: Controls the base material's roughness. For wood, you might want moderate roughness (0.4-0.7) to show the grain while still having some shine.

The clearcoat properties work independently from the base material's metalness and roughness, so you can have a rough wooden base with a smooth, glossy clearcoat on top.

## Code

in repo - `apps/10_11_1_clearcoat`

```ts
import * as THREE from 'three/webgpu';

// Create MeshPhysicalMaterial
const material = new THREE.MeshPhysicalMaterial();

// Load and apply base material textures
material.map = doorAlbedoTexture; // Base color
material.aoMap = doorAmbientOcclusionTexture;
material.normalMap = doorNormalTexture;
material.metalnessMap = doorMetallnessTexture;
material.roughnessMap = doorRoughnessTexture;

// Base material properties (adjust based on your texture)
material.metalness = 0.3; // Lower for wood
material.roughness = 0.5; // Moderate for wood grain

// Clearcoat properties - the main focus
material.clearcoat = 1.0; // Full clearcoat effect
material.clearcoatRoughness = 0.0; // Smooth, mirror-like clearcoat

// Create mesh
const mesh = new THREE.Mesh(geometry, material);
```

### GUI Controls for Clearcoat

```ts
// Add clearcoat controls to GUI
gui.add(material, 'clearcoat').min(0).max(1).step(0.0001);
gui.add(material, 'clearcoatRoughness').min(0).max(1).step(0.0001);
```

## Gotchas

1. **Clearcoat is separate from base roughness**: Don't confuse `roughness` (base material) with `clearcoatRoughness` (clearcoat layer). They control different layers.

2. **Metalness affects the entire surface**: High metalness values will make the base material look metallic, which might not be what you want for materials like wood. Use `metalnessMap` to control which parts are metallic (like metal hinges on a wooden door).

3. **Clearcoat needs proper lighting**: The clearcoat effect is most visible with good environment maps or lighting. Without proper reflections, the clearcoat won't be noticeable.

4. **Performance consideration**: `MeshPhysicalMaterial` is more expensive than `MeshStandardMaterial`. Only use it when you need the clearcoat or other physical material features.

## Revisit

- Experiment with different `clearcoatRoughness` values to see how the clearcoat layer changes from mirror-like to diffuse
- Try combining clearcoat with other MeshPhysicalMaterial properties like `iridescence` or `transmission`
- Test how the clearcoat effect looks with different environment maps
- Consider using `MeshStandardMaterial` when clearcoat isn't needed for better performance
