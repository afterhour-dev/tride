# Transmission

## Concept

The `transmission` property on [[10.11.0_mesh-physical-material|MeshPhysicalMaterial]] enables light to pass through a material, creating a translucent or glass-like effect. This is fundamentally different from simple transparency via the `opacity` property — transmission actually refracts and deforms the image behind the object, simulating real-world light behavior through translucent surfaces.

### Key Properties

- **`transmission`** (0–1): Controls how much light passes through. At 1, the material is fully translucent; at 0, it behaves like a regular opaque material.
- **`ior`** (Index of Refraction): Determines how much light bends as it passes through. Different materials have distinct IOR values:
  - Air: ~1.000293
  - Water: 1.333
  - Glass: ~1.5
  - Diamond: 2.417
- **`thickness`**: A fixed value representing the apparent thickness of the material. Importantly, this does **not** use the actual geometry thickness — it's a uniform value applied across the entire surface. This affects how much the light bends and how much distortion you see.

### Why Thickness Doesn't Use Geometry

Three.js doesn't calculate the actual thickness of your mesh. Instead, `thickness` is a uniform value that tells the shader how thick the material "appears." A thin plane with `thickness: 1.0` will look just as thick as a sphere with the same value. This is a simplification — real-world glass of varying thickness would refract differently at different points.

### Metalness and Roughness with Transmission

For a clean glass or water effect, set `metalness = 0` and `roughness = 0`. Increasing roughness creates a frosted glass look, while metalness doesn't really make physical sense with transmission (metals are opaque in the real world).

### Textures and Transmission

You can apply textures (albedo, normal, displacement, etc.) on top of a transmission material, but it changes the look significantly — the material becomes a textured translucent surface rather than clean glass. Comment textures in and out to see the difference.

## Code

in repo - `apps/10_11_4_transmission`

```ts
import * as THREE from 'three/webgpu';

const material = new THREE.MeshPhysicalMaterial();

// Clean glass settings
material.metalness = 0;
material.roughness = 0;

// Transmission properties
material.transmission = 1;  // fully translucent
material.ior = 1.5;         // glass-like refraction
material.thickness = 0.5;   // apparent thickness

// Apply to any mesh
const mesh = new THREE.Mesh(geometry, material);
```

### GUI Controls

The app exposes `transmission`, `ior`, and `thickness` via lil-gui for live tweaking. Other properties (displacement, segments, normalScale) are mostly disabled — they're leftovers from previous lessons.

## Gotchas

- **`thickness` is not geometry-aware**: A flat plane with `thickness: 1.0` looks the same as a sphere with the same value. Don't expect it to behave like real-world glass thickness.
- **IOR values are material-specific**: Using `ior: 2.417` on a material that's supposed to be water will look wrong. Match the IOR to the material you're simulating.
- **Metalness should stay 0**: Transmission + metalness doesn't make physical sense. Keep `metalness = 0` for realistic glass/water effects.
- **Performance**: Transmission requires an extra render pass behind the object. High polygon counts + transmission can be expensive.

## Revisit

- Experiment with different IOR values to see how refraction changes — try water (1.333) vs diamond (2.417)
- Toggle textures on and off while `transmission = 1` to see the difference between textured translucent and clean glass
- Try setting `roughness` to non-zero values with transmission enabled for a frosted glass effect
- Compare `transmission` vs `opacity` on the same geometry to understand why they're fundamentally different
