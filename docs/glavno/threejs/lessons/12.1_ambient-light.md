# Ambient Light

Adding ambient light to a Three.js scene — the simplest light type that provides uniform, omnidirectional illumination from all directions.

## Concept

Adding lights to a Three.js scene is as straightforward as adding meshes: instantiate the light class with the right parameters and call `scene.add()`. Ambient light is one of the simplest light types, yet it plays a crucial role in making scenes look natural.

### What is Ambient Light?

Ambient light provides **omnidirectional lighting** — rays of light coming from every direction simultaneously, illuminating all surfaces equally regardless of their orientation. Unlike directional or point lights, ambient light has no single source point or direction.

![[ambient.png]]

This uniform illumination means that even crevices, recessed areas, and surfaces facing away from other light sources receive the same amount of light. In the real world, this doesn't happen — but in 3D rendering, ambient light fills in the dark areas that would otherwise appear black.

### Simulating Light Bouncing

![[light-bouncing.png]]

In the real world, light bounces off surfaces and indirectly illuminates other objects. For example:

1. A light source emits rays in straight lines
2. These rays hit an object and illuminate the surfaces facing the light
3. The rays bounce off the object (or the ground) and reach the opposite side
4. This "bounce light" softly illuminates areas not in direct light

Real-time rendering of light bouncing (global illumination) is computationally expensive. Ambient light is a cheap approximation — it adds a small, uniform dim light from all directions to simulate the effect of bounced light. While not physically accurate, it prevents unlit surfaces from being completely black.

### Color and Intensity

Ambient light accepts two main parameters:

- **`color`** — the color of the ambient illumination (default: `0xffffff`, white)
- **`intensity`** — how bright the ambient light is (default: `1`)

You can also instantiate `AmbientLight()` without parameters and set `color` and `intensity` later, which is useful for GUI tweaking with lil-gui.

### The Role of MeshStandardMaterial

The app uses `MeshStandardMaterial` with `roughness = 0.4`. This is a physically-based material that **requires** light sources to be visible. Without any lights, `MeshStandardMaterial` surfaces appear completely black. The ambient light provides the minimum illumination needed for these materials to be seen.

## Code

in repo - `apps/12_1_ambient_light`

```ts
import * as THREE from 'three/webgpu';

const canvas = document.querySelector<HTMLCanvasElement>('canvas#tride')!;

async function init() {
  const scene = new THREE.Scene();

  const renderer = new THREE.WebGPURenderer({ canvas });
  await renderer.init();

  // Ambient light — omnidirectional, uniform illumination
  const ambientLight = new THREE.AmbientLight();
  ambientLight.color = new THREE.Color(0xffffff);
  ambientLight.intensity = 0.5;
  scene.add(ambientLight);

  // MeshStandardMaterial requires lights to be visible
  const material = new THREE.MeshStandardMaterial();
  material.roughness = 0.4;

  // Geometry
  const boxMesh = new THREE.Mesh(new THREE.BoxGeometry(0.75, 0.75, 0.75), material);
  const sphereMesh = new THREE.Mesh(new THREE.SphereGeometry(0.5, 32, 32), material);
  sphereMesh.position.x = -1.5;

  scene.add(boxMesh, sphereMesh);

  // Camera
  const camera = new THREE.PerspectiveCamera(75, innerWidth / innerHeight, 0.1, 100);
  camera.position.set(2, 1, 1);
  scene.add(camera);

  // Render loop
  renderer.setPixelRatio(Math.min(devicePixelRatio, 2));
  renderer.setSize(innerWidth, innerHeight);

  renderer.setAnimationLoop(() => {
    renderer.render(scene, camera);
  });
}

await init();
```

## Gotchas

- **`MeshStandardMaterial` without lights = black.** Unlike `MeshBasicMaterial`, standard/physical materials require light sources to be visible. If you remove all lights, objects disappear into the background.

- **`await renderer.init()` is mandatory for WebGPU.** The WebGPU renderer needs an async initialization step before it can render. Forgetting this will throw or produce a blank canvas.

- **Ambient light alone can look flat.** Ambient light provides uniform illumination with no shadows or highlights. It's meant to be combined with other light types (point, directional, spot) for realistic scenes. Using only ambient light makes everything look equally lit from all angles.

- **Ambient light does not cast shadows.** Since ambient light has no single direction, it cannot produce shadow maps. You need directional or spot lights for shadows.

## Revisit

- Combine ambient light with a `PointLight` or `DirectionalLight` to see how ambient light fills in the dark areas that direct lights leave behind.

- Experiment with colored ambient light (e.g., a warm orange or cool blue) to see how it tinted the entire scene — useful for simulating environmental mood (sunset, underwater, etc.).

- Try setting `ambientLight.intensity` to `0` and compare the scene with and without ambient light — this makes the role of ambient illumination obvious.

- Look into `HemisphereLight` as a more advanced alternative to ambient light — it simulates sky/ground color difference, giving a more natural result than uniform ambient light.
