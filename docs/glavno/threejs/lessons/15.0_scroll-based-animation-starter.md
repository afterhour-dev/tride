## Concept

This lesson lays the foundation for integrating a Three.js scene as the **background of a classic HTML page** — instead of the 3D scene filling the entire viewport, HTML content scrolls normally on top of it. The camera moves in sync with the scroll position, creating the illusion that the 3D objects are part of the page layout.

The key architectural insight: the Three.js canvas is positioned `fixed` (covering the viewport behind the page content), while HTML sections scroll naturally above it. The camera's Z or Y position is driven by the scroll offset, so different sections of the scene align with different HTML sections.

This starter project provides the scaffolding:

- **WebGPU renderer** — using `THREE.WebGPURenderer` (imported from `three/webgpu`)
- **A cube** with `MeshBasicMaterial` and adjustable color via lil-gui
- **Three HTML sections** (`sekcija` — Serbian for "section") with styled text
- **CSS variables** for a full color design system
- **No OrbitControls** — the camera is controlled programmatically

### CSS Setup

The canvas uses `position: fixed` so it stays behind everything as a static background. The HTML body has `overflow-x: hidden` (but NOT `overflow: hidden` — vertical scrolling is preserved). Each `<section class="sekcija">` takes `height: 100vh` so sections stack as full-viewport blocks.

### Fonts

Three variable fonts are imported (though not heavily used in the starter yet):

- **Manrope** (sans-serif, weights 200–900)
- **Bitter** (serif, weights 100–900)
- **Fira Code** (monospace, weights 300–700)

```ts
import * as THREE from 'three/webgpu';
import GUI from 'lil-gui';
import { getRequiredElement } from './util';

const canvas = getRequiredElement<HTMLCanvasElement>('canvas#tride');

// GUI setup
const gui = new GUI({ width: 300, title: 'Tweaks', closeFolders: true });
const debugObject = { cubeColor: new THREE.Color('#ac3d3d') };
const cubeTweaks = gui.addFolder('cube Mesh');
cubeTweaks.open();

const sizes = { width: window.innerWidth, height: window.innerHeight };

async function init() {
  const scene = new THREE.Scene();

  // Renderer
  const renderer = new THREE.WebGPURenderer({ canvas });
  await renderer.init();

  // Cube
  const cubeGeo = new THREE.BoxGeometry(1, 1, 1);
  const cubeMat = new THREE.MeshBasicMaterial({ color: debugObject.cubeColor });
  const cubeMesh = new THREE.Mesh(cubeGeo, cubeMat);
  scene.add(cubeMesh);

  // Camera
  const camera = new THREE.PerspectiveCamera(75, sizes.width / sizes.height, 0.1, 100);
  camera.position.z = 3;
  scene.add(camera);

  // GUI controls for cube
  cubeTweaks.addColor(debugObject, 'cubeColor')
    .onChange((col) => cubeMat.color.set(col));
  cubeTweaks.add(cubeMesh.position, 'x').step(0.001).min(-5).max(5);
  cubeTweaks.add(cubeMesh.position, 'y').step(0.001).min(0).max(5);
  cubeTweaks.add(cubeMesh.position, 'z').step(0.001).min(-5).max(5);

  // Renderer config
  renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));
  renderer.setSize(sizes.width, sizes.height);
  renderer.setClearColor(0x000000, 1);

  // Animation loop
  const timer = new THREE.Timer();
  renderer.setAnimationLoop(tick);

  function tick(timestamp: number) {
    timer.update(timestamp);
    renderer.render(scene, camera);
  }

  // Resize
  window.addEventListener('resize', () => {
    sizes.width = window.innerWidth;
    sizes.height = window.innerHeight;
    camera.aspect = sizes.width / sizes.height;
    camera.updateProjectionMatrix();
    renderer.setSize(sizes.width, sizes.height);
  });

  // Fullscreen toggle on double-click
  window.addEventListener('dblclick', () => {
    const fsEl = document.fullscreenElement || (document as any).webkitExitFullscreenExit;
    if (!fsEl) {
      canvas.requestFullscreen?.();
      (canvas as any).webkitRequestFullScreen?.();
    } else {
      document.exitFullscreen?.();
      (document as any).webkitExitFullscreen?.();
    }
  });

  // Toggle GUI with 'h' key
  window.addEventListener('keydown', (ev) => {
    if (ev.key === 'h') gui.show(gui._hidden);
  });
}

await init();
```

## Gotchas

- **Canvas positioning**: The Three.js canvas must use `position: fixed` (or `absolute`) so it sits behind the HTML content. If it's `position: static` (default), the HTML sections will push it out of view.
- **Scroll overflow**: Don't set `overflow: hidden` on `body` — that kills scrolling entirely. Use `overflow-x: hidden` only to hide horizontal scrollbars.
- **WebGPU renderer needs `await renderer.init()`**: Unlike `WebGLRenderer`, `WebGPURenderer.init()` is async and must be awaited before anything else happens.
- **No OrbitControls**: This is intentional — in a scroll-driven scene, controls are replaced by programmatic camera movement tied to the scroll position.

## Revisit

This is a **starter** project. The next steps are:

- Read `window.scrollY` and map it to camera position so the cube (or scene) moves as the user scrolls
- Add parallax effects by reacting to mouse position
- Trigger animations when a specific HTML section is in view
- Replace the placeholder cube with scene content that matches the page sections
