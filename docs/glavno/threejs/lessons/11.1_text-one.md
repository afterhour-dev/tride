# 11.1 Text One

## Concept

This lesson introduces **TextGeometry** (formerly `TextBufferGeometry`) — a way to render 3D text in the scene using Three.js. Text geometry works by taking a font file (in **typeface.json** format) and generating a 3D mesh from a string.

### What is a Typeface?

A **typeface** is a font file in JSON format that describes glyph outlines. Three.js uses this format to create text geometry. You can obtain typeface fonts in three ways:

1. **Download from Three.js repo** — fonts live in `three/examples/fonts` on GitHub: https://github.com/mrdoob/three.js/tree/dev/examples/fonts. Copy the `.typeface.json` file and its `LICENCE.txt` into your `/public/fonts/` folder.

2. **Convert Google Fonts** — use the [Facetype.js converter](https://gero3.github.io/facetype.js/) to convert any Google Font to typeface format. Make sure the licence is **SIL Open Font License (OFL)**, not Apache License 2.0. ⚠️ Some fonts may have rendering issues with certain characters (e.g. Cyrillic `в` with filled bottom holes).

3. **Import from node_modules** — this used to work via `import typefaceFont from "three/examples/fonts/helvetiker_regular.typeface.json"` but may no longer work in recent Three.js versions.

### Loading Fonts

We use `FontLoader` with `loadAsync` to load the font file asynchronously:

```ts
import { FontLoader } from 'three/addons/loaders/FontLoader.js';

const fontLoader = new FontLoader();
const font = await fontLoader.loadAsync('/fonts/bitter/Bitter_Regular.json');
```

There are two import paths for `FontLoader` — both work:
- `three/examples/jsm/loaders/FontLoader.js` (older style)
- `three/addons/loaders/FontLoader.js` (newer, preferred style)

### Creating TextGeometry

Once you have the font, create a `TextGeometry` with the desired parameters:

```ts
import { TextGeometry } from 'three/addons/geometries/TextGeometry.js';

const textGeometry = new TextGeometry('Ћао Здраво из Три.џејеса!', {
  font,
  size: 0.5,          // text height
  depth: 0.2,         // extrusion depth (was called `height` in older versions)
  curveSegments: 5,   // controls curve smoothness (lower = fewer faces)
  bevelEnabled: true,
  bevelThickness: 0.03,
  bevelSize: 0.02,
  bevelOffset: 0,
  bevelSegments: 4,   // bevel smoothness (lower = fewer faces)
});
```

Then attach it to a mesh:

```ts
const textMaterial = new THREE.MeshBasicMaterial();
const text = new THREE.Mesh(textGeometry, textMaterial);
scene.add(text);
```

### Performance

Creating text geometry is **computationally expensive**. Keep `curveSegments` and `bevelSegments` as low as possible while still looking acceptable. Avoid creating text geometry dynamically at runtime — load it once and reuse the geometry.

## Code

in repo - `apps/11_1_text_one`

```ts
import * as THREE from 'three/webgpu';
import { FontLoader } from 'three/addons/loaders/FontLoader.js';
import { TextGeometry } from 'three/addons/geometries/TextGeometry.js';

const canvas = document.querySelector<HTMLCanvasElement>('canvas#tride')!;

async function init() {
  const scene = new THREE.Scene();
  const renderer = new THREE.WebGPURenderer({ canvas });
  await renderer.init();

  // Load font (typeface.json format)
  const fontLoader = new FontLoader();
  const font = await fontLoader.loadAsync('/fonts/bitter/Bitter_Regular.json');

  // Create 3D text geometry
  const textGeometry = new TextGeometry('Ћао Здраво из Три.џејеса!', {
    font,
    size: 0.5,
    depth: 0.2,
    curveSegments: 5,
    bevelEnabled: true,
    bevelThickness: 0.03,
    bevelSize: 0.02,
    bevelOffset: 0,
    bevelSegments: 4,
  });

  const textMaterial = new THREE.MeshBasicMaterial();
  const text = new THREE.Mesh(textGeometry, textMaterial);
  scene.add(text);

  const camera = new THREE.PerspectiveCamera(75, window.innerWidth / window.innerHeight, 0.1, 100);
  camera.position.set(1, 1.5, 3);
  scene.add(camera);

  renderer.setSize(window.innerWidth, window.innerHeight);
  renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));
  renderer.setAnimationLoop(() => renderer.render(scene, camera));
}

init();
```

## Gotchas

- **Font licensing** — when using a downloaded typeface, always include the `LICENCE.txt` or `OFL.txt` file. Apache-licensed fonts may have usage restrictions.

- **Cyrillic rendering issues** — some fonts converted via Facetype.js render Cyrillic characters incorrectly (e.g. filled holes in `в`). Test your font with the actual text you plan to display before committing to it.

- **`height` → `depth` rename** — in older Three.js versions the extrusion parameter was called `height`. In current versions it's `depth`. Using the wrong name silently does nothing.

- **Import paths** — there are two styles of importing addons:
  - `three/examples/jsm/...` (older)
  - `three/addons/...` (newer, preferred)

  Both work, but the newer style is more future-proof.

- **Performance** — text geometry creation is heavy. Don't create it in a loop or on every frame. Create once, reuse the geometry.
