# Text with Matcap Material

## Concept

So far our text geometry has used `MeshBasicMaterial` — a flat, unlit surface. In this lesson we switch to `MeshMatcapMaterial`, which gives the text a polished, glossy look with almost zero effort.

**What is a matcap?** A matcap (material capture) is a small image — typically 256×256 or 512×512 pixels — that encodes how a sphere would look under a particular lighting and material setup. Three.js reads the pixel color at the position corresponding to the surface normal and uses that as the final color. The result is a pre-baked "look" that doesn't need real lights, environment maps, or PBR calculations. It's fast, cheap, and visually striking.

### Loading a matcap texture

```ts
const matcapTexture = textureLoader.load('/textures/matcaps/8.png');
matcapTexture.colorSpace = THREE.SRGBColorSpace;
```

> The `colorSpace = SRGBColorSpace` line is important — without it the matcap will look washed out or overly dark, because the texture data is in sRGB but Three.js would otherwise treat it as linear.

### Applying the matcap to text

```ts
const textMaterial = new THREE.MeshMatcapMaterial({
  matcap: matcapTexture,
});
```

Note that you set the texture via the `matcap` property, **not** `map`. Using `map` would just apply it as a regular diffuse texture and you'd lose the matcap effect entirely.

### Matcap texture sources

The matcap images in this project come from the [nidorx/matcaps](https://github.com/nidorx/matcaps) collection — a curated library of hundreds of matcap textures in various resolutions. Download whichever resolution you like; the app uses 512×512, though 256×256 is also common and perfectly fine for most use cases. The visual difference is minimal unless you're rendering very large surfaces up close.

### Reusing geometry and material for performance

The code creates a single `TorusGeometry` and a single `MeshMatcapMaterial`, then reuses them for all 100 donuts:

```ts
const donutGeometry = new THREE.TorusGeometry(0.3, 0.2, 20, 45);
const donutMaterial = new THREE.MeshMatcapMaterial();
```

This means Three.js only uploads one geometry and one material to the GPU. Each `Mesh` just references the same objects — much cheaper than creating 100 separate geometries and materials.

### Random positioning math

```ts
donut.position.x = (Math.random() - 0.5) * 10;
```

`Math.random()` gives a value between 0 and 1. Subtracting 0.5 shifts it to the range `[-0.5, 0.5]`. Multiplying by 10 scales it to `[-5, 5]`. This centers the random distribution around the origin rather than clustering everything in the positive quadrant.


## Gotchas

- **Using `map` instead of `matcap`** — The `MeshMatcapMaterial` has a `matcap` property, not `map`. Setting `map` won't produce the expected result.
- **Forgetting `colorSpace = SRGBColorSpace`** — Without this, the matcap texture will look wrong (too dark or washed out) because the GPU interprets the sRGB pixel values as linear data.
