# MeshBasicMaterial

## Concept

Materials in Three.js control the color and appearance of every visible pixel on a geometry. The algorithms that compute each pixel's final color are programs called **shaders**, and Three.js ships many built-in materials with pre-made shaders so you don't have to write them from scratch.

`MeshBasicMaterial` is the simplest of these built-in materials. It ignores lighting entirely — objects appear flat, as if lit from every direction equally. Despite being "basic," it exposes several properties that are shared across many other material types (like `MeshStandardMaterial` or `MeshPhysicalMaterial`), which is why this lesson covers them now rather than re-explaining them in every future material lesson.

### Setting properties

Properties can be set in two ways — at instantiation via the options object, or afterward on the instance:

```ts
// At instantiation
const material = new THREE.MeshBasicMaterial({
  map: doorAlbedoTexture,
});

// After instantiation
material.map = doorAlbedoTexture;
```

The lesson code uses the post-instantiation approach for clarity, but both work identically.

### Color

`MeshBasicMaterial` has a `color` property that tints the object. When setting color at instantiation, you can pass a raw hex number (`0x59b4af`) or a string (`'cyan'`, `'rgb(89, 180, 175)'`). However, when setting color **after** instantiation, you must use a `THREE.Color` instance:

```ts
// ✅ works after instantiation
material.color = new THREE.Color('#59b4af');
material.color = new THREE.Color(0x59b4af);
material.color = new THREE.Color('cyan');
material.color = new THREE.Color('rgb(89, 180, 175)');
```

Combining `color` with a `map` (texture) tints the texture — the texture's colors get multiplied by the material's color.

### Wireframe

```ts
material.wireframe = true;
```

Renders the geometry as a wireframe mesh. In production, this is rarely used because the line thickness is always exactly 1 pixel regardless of distance. It's mostly a debugging helper to visualize geometry subdivisions.

### Opacity and transparency

Opacity and transparency work as a pair and can be unintuitive:

```ts
material.transparent = true;  // enables transparency support
material.opacity = 0.0;       // fully invisible
material.opacity = 0.1;       // barely visible
material.opacity = 1.0;       // fully opaque (default)
```

Setting `transparent = true` alone does **nothing visible** — you must also set `opacity` to a value below 1.0. Setting `opacity` below 1.0 without `transparent = true` also won't produce visible transparency. Both must be set together.

### AlphaMap

An alpha map is a grayscale texture that controls per-pixel transparency:

```ts
material.transparent = true;
material.alphaMap = doorAlphaTexture;
```

Black pixels in the alpha map become transparent; white pixels stay opaque.

### Side

Controls which face(s) of a geometry are rendered:

```ts
material.side = THREE.FrontSide;   // default — only front faces
material.side = THREE.BackSide;    // only back faces
material.side = THREE.DoubleSide;  // both sides
```

`DoubleSide` is generally bad for performance because the GPU has to render both faces of every triangle. When exporting models from Blender, make sure not to export with DoubleSide enabled unless truly needed.

### Shared properties

Properties like `opacity`, `transparent`, `wireframe`, `side`, and `alphaMap` are not unique to `MeshBasicMaterial` — they appear on most other Three.js materials too. Future material lessons will not re-explain these; they're covered here once and reused everywhere.

  '/textures/wooden_door/Door_Wood_001_opacity.jpg',

const sizes = {
  width: window.innerWidth,
  height: window.innerHeight,

async function init() {
  const scene = new THREE.Scene();

  doorAlbedoTexture.colorSpace = THREE.SRGBColorSpace;

  // --- Geometry + Material + Mesh ---

  const boxGeometry = new THREE.BoxGeometry(1, 1, 1);
  const sphereGeometry = new THREE.SphereGeometry(0.5, 16, 16);
  const planeGeometry = new THREE.PlaneGeometry(1, 1);
  const torusGeometry = new THREE.TorusGeometry(0.3, 0.2, 16, 32);

  const material = new THREE.MeshBasicMaterial({
    color: 0x59b4af,
  });

  // Try these properties one at a time:
  // material.map = doorAlbedoTexture;
  // material.wireframe = true;
  // material.transparent = true;
  // material.opacity = 0.5;
  // material.alphaMap = doorAlphaTexture;
  // material.side = THREE.DoubleSide;

  const boxMesh = new THREE.Mesh(boxGeometry, material);
  boxMesh.position.x = 4;

  const sphereMesh = new THREE.Mesh(sphereGeometry, material);
  sphereMesh.position.x = -1.5;

  const planeMesh = new THREE.Mesh(planeGeometry, material);

  const torusMesh = new THREE.Mesh(torusGeometry, material);
  torusMesh.position.x = 1.5;

  scene.add(torusMesh, sphereMesh, boxMesh, planeMesh);

  // --- Camera ---

  const camera = new THREE.PerspectiveCamera(
    75,
    sizes.width / sizes.height,
    0.1,
    100,
  );
  camera.position.set(1, 1.5, 3);
  scene.add(camera);

  // --- Controls ---

  const orbitControls = new OrbitControls(camera, canvas);
  orbitControls.enableDamping = true;

  // --- Renderer ---

  const renderer = new THREE.WebGPURenderer({ canvas });
  await renderer.init();
  renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));
  renderer.setSize(sizes.width, sizes.height);
  renderer.setClearColor(0x000000, 1);
  renderer.render(scene, camera);

  // --- Resize ---

  window.addEventListener('resize', () => {
    sizes.width = window.innerWidth;
    sizes.height = window.innerHeight;
    camera.aspect = sizes.width / sizes.height;
    camera.updateProjectionMatrix();
    renderer.setSize(sizes.width, sizes.height);
    renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));
  });

  // --- Animation loop ---

  const timer = new THREE.Timer();

  function tick(timestamp: number) {
    timer.update(timestamp);
    const elapsedTime = timer.getElapsed();

    orbitControls.update();

    planeMesh.rotation.y = elapsedTime * 0.1;
    sphereMesh.rotation.y = elapsedTime * 0.1;
    torusMesh.rotation.y = elapsedTime * 0.1;

    planeMesh.rotation.x = -0.15 * elapsedTime;
    sphereMesh.rotation.x = -0.15 * elapsedTime;
    torusMesh.rotation.x = -0.15 * elapsedTime;

    renderer.render(scene, camera);
    window.requestAnimationFrame(tick);
  }

  window.requestAnimationFrame(tick);
}

await init();

## Gotchas

- **`transparent = true` alone does nothing.** You must also set `opacity` to a value below 1.0 to see any transparency. Both must be set together — this is a common source of confusion.

- **Color must be a `THREE.Color` instance after instantiation.** Unlike setting color in the constructor options (where raw hex/strings work), setting `material.color = '#59b4af'` after instantiation won't work — you need `material.color = new THREE.Color('#59b4af')`.

- **Wireframe line thickness is always 1 pixel.** It doesn't scale with distance or zoom, so it looks different at different camera distances. Mostly useful as a debugging/visualization tool, not for production visuals.

- **`DoubleSide` hurts performance.** The GPU renders both faces of every triangle. Avoid it unless you genuinely need to see both sides. Also make sure Blender exports don't include DoubleSide unless needed.

- **Color space matters for textures.** When loading color/albedo textures, set `texture.colorSpace = THREE.SRGBColorSpace` to get correct color reproduction.

## Revisit

- These shared properties (`opacity`, `transparent`, `wireframe`, `side`, `alphaMap`) will appear again in future material lessons — don't forget them.

- Try combining `color` + `map` together to see how the tinting works.

- Experiment with different `side` values on a plane geometry to really see the difference between `FrontSide`, `BackSide`, and `DoubleSide`.
