## Concept

Iridescence is a material property that creates color artifacts that shift depending on the viewing angle — the same effect you see on soap bubbles, oil slicks, beetle shells, or the rainbow shimmer on a CD/LaserDisc surface.

In Three.js, iridescence is part of [`MeshPhysicalMaterial`](https://threejs.org/docs/#api/en/materials/MeshPhysicalMaterial) and is controlled by three properties:

- **`iridescence`** (0–1) — intensity of the iridescence effect. At 0 there's no iridescence; at 1 the effect is fully visible.
- **`iridescenceIOR`** (0–2.333) — the index of refraction of the thin iridescent film. Different IOR values shift which wavelengths of light interfere constructively, changing the color palette. A value of 1.0 is a good starting point.
- **`iridescenceThicknessRange`** ([min, max]) — the range of the thin-film thickness in nanometers. The actual thickness at any point on the surface is interpolated between these two values based on the viewing angle. A range like `[100, 800]` covers most visible wavelengths and produces a full rainbow effect.

### Metalness and roughness with iridescence

Iridescence works best when **metalness is low** (0 or close to 0) and **roughness is moderate** (around 0.5). High metalness tends to overpower the iridescent color shift with metallic reflections, and very low roughness makes the surface too mirror-like to show the effect clearly. These are good starting values to tweak from:

```ts
material.metalness = 0;
material.roughness = 0.5;
material.iridescence = 1;
material.iridescenceIOR = 1;
material.iridescenceThicknessRange = [100, 800];
```

### How it works (briefly)

The iridescence effect is based on **thin-film interference** — the same physics that makes soap bubbles shimmer. Light reflects off both the top and bottom surfaces of an imaginary thin film on the material. Depending on the film thickness and the viewing angle, certain wavelengths cancel out and others amplify, producing shifting colors.

> 🤖 suggested: For a deeper dive into the thin-film interference math, see the PBR book's section on iridescence — linked in Resources below.

## Code

in repo - `apps/10_11_3_iridescence`

```ts
import * as THREE from 'three/webgpu';

const material = new THREE.MeshPhysicalMaterial();

// Base PBR properties
material.metalness = 0;
material.roughness = 0.5;

// Iridescence
material.iridescence = 1;
material.iridescenceIOR = 1;
material.iridescenceThicknessRange = [100, 800];

const mesh = new THREE.Mesh(new THREE.SphereGeometry(0.5, 64, 64), material);
scene.add(mesh);
```

The full app applies this material to a sphere, torus, plane, and box, all rotating, with an HDR environment map for realistic reflections and a `lil-gui` panel for live-tweaking every property.

## Gotchas

- **Metalness must be low.** Setting `metalness` to 1 drowns out the iridescent color shift with strong metallic reflections. Keep it at 0 or very close to 0 to see the effect properly.
- **Need an environment map.** Iridescence interacts with reflected light. Without an environment map (or lights), the effect can look flat or invisible.
- **Thickness range matters a lot.** A narrow range (e.g. `[200, 300]`) produces subtle, restricted colors. A wide range like `[100, 800]` gives a full rainbow. Experiment with the bounds to control the color spread.
- **IOR range is capped at 2.333.** Three.js clamps `iridescenceIOR` to this max. Values above this don't make physical sense for most thin-film materials.

## Revisit

- Try iridescence on different geometries — curved surfaces (spheres, toruses) show the angle-dependent color shift much better than flat planes.
- Combine iridescence with other `MeshPhysicalMaterial` properties like clearcoat or sheen for more complex layered materials.
- Compare the effect with different HDR environment maps to see how lighting changes the iridescent colors.
