# 10.11.2 sheen

## Concept

The **sheen** effect on [`MeshPhysicalMaterial`](https://threejs.org/docs/#api/en/materials/MeshPhysicalMaterial) simulates the soft, velvety highlight you see on fabrics like velvet, silk, or suede when viewed at a narrow (grazing) angle. This is a physically motivated effect — real-world fibrous materials scatter light differently at shallow angles, and sheen models that behavior.

Sheen is controlled by three properties:

- **`sheen`** — intensity of the sheen effect (0 = off, 1 = standard, up to 2 for extra-strong). Higher values make the grazing-angle highlight brighter.
- **`sheenRoughness`** — how blurry or sharp the sheen highlight is. Lower values give a tighter, more focused highlight; higher values spread it out. Range: 0–1.
- **`sheenColor`** — the color of the sheen highlight. In real life this is often a lighter or slightly different hue from the base material color.

Sheen works best when combined with high `roughness` (1.0) on the base material — this simulates a matte, fabric-like surface. Setting roughness too low makes the sheen hard to see because the specular highlight dominates. `metalness` should generally be 0 (or low) for fabric-like materials.

The key visual behavior: **rotate the camera** around the object. Sheen becomes visible at narrow (grazing) viewing angles and fades when you look at the surface head-on.

## Code

in repo - `apps/10_11_2_sheen`

```ts
const material = new THREE.MeshPhysicalMaterial();

// Base PBR properties
material.metalnessMap = doorMetallnessTexture;
material.roughnessMap = doorRoughnessTexture;
material.metalness = 0;
material.roughness = 1;
material.normalMap = doorNormalTexture;
material.normalScale.set(0.5, 0.5);

// Sheen effect — the core of this lesson
material.sheen = 1;               // intensity (0–2)
material.sheenRoughness = 0.25;   // highlight sharpness (0–1)
material.sheenColor.set(1, 1, 1); // sheen highlight color (white)

// GUI controls for tweaking
gui.add(material, 'sheen').min(0).max(2).step(0.0001);
gui.add(material, 'sheenRoughness').min(0).max(2).step(0.0001);
gui.addColor(material, 'sheenColor');
```

## Gotchas

- **Metalness & roughness values matter.** Sheen is most visible on matte surfaces (roughness ≈ 1). If roughness is too low, the specular highlight overshadows the sheen effect. With metalness=1 + roughness=1 the sheen is very prominent; try lowering roughness to see it disappear.
- **You must orbit the camera.** Sheen only shows up at narrow/grazing angles. If you're looking head-on at a surface, you'll see nothing special — rotate to confirm the effect is working.
- **`sheenRoughness` can exceed 1.** The GUI allows values up to 2. Values above 1 create an extremely diffused sheen that may look washed out.
- **Environment map is essential.** Sheen relies on the environment reflection. Without `scene.environment = hdrTexture`, the effect won't render correctly.

## Revisit

- Try changing `sheenColor` from white to a warm or cool tint to see how it interacts with the base albedo texture — this is how real fabric looks different from different angles.
- Compare the sheen on the sphere (curved surface shows angle variation smoothly) vs the box (sharp edges create abrupt angle changes).
