# Doing matrix operation visually

We can actually do matrix operation visually, instead of going through all math steps.

Let's look at identity matrix (cube matrix with all zeros, but ones only across diagonal from left to right; the matrix if we multiply it with other matrix gives us identical matrix we multiplied identity matrix with)

But we don't have intuition what exactly identity matrix represents.

Think of identity matrix as two direction vectors, one representin x axis and other representing y axis

![[2026-09-24_20-09.png]]

Mentioned vectors are your basis vectors, they represent base vectors of your space, So we have two vectors (1,0) and (0,1)
![[2026-09-24_20-11.png]]

So this identity matrix represent graph itself.

In past when we looked at the graph x axis, and we can notice that `(1,0)` is unit vector for the x axis; if you forgot unit vector has lenghth of 1, and if unit vector agrees (overlaps) with x axis, his coordinates are (1,0)

And (0,1) Vector is unit vector for the y axis in a same mannor (1,0) is for x

**Together these two mentioned vectors (x uinit vector and y unit vector or (1,0) and (0,1)) form the basis of the 2D crafts we looked in may lessons since now**

**So, take these two unit vectors and they form identity matrix**.
