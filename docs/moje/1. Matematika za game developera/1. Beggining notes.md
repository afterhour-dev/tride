# Cartesian coordinate system and points

In game development representation of a specific location in virtual spece in the world we use  term `Point` or `Position` or `Position Vector`; so they are used interchangeably; underlying concept is the same.

# Simple Distance between two points is absolute value

Meaning always the positive; and in typescript we can use `Math.abs(p2 - p1)`; so the order of values doesn't matter if we use abs.
