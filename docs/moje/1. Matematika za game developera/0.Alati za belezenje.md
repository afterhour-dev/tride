**LaTeX Suite default snippets (confirmed, stable set)**

|Trigger (type this)|Expands to|Renders as|
|---|---|---|
|`dm`|enters display math block `$$ $$`|—|
|`mk`|enters inline math `$ $`|—|
|`sqx`|`\sqrt{x}`|$\sqrt{x}$|
|`x/y` then `Tab`|`\frac{x}{y}` (auto-fraction)|$\frac{x}{y}$|
|`xsr`|`x^{2}`|$x^{2}$|
|`sin @t`|`\sin \theta`|$\sin \theta$|
|`sum` then `Tab`|`\sum_{i=1}^{N}`|$\sum_{i=1}^{N}$|
|`par` `Tab` `f` `Tab` `x` `Tab`|`\frac{\partial f}{\partial x}`|$\frac{\partial f}{\partial x}$|
|`dint` `Tab` `2pi` `Tab` `sin @t` `Tab` `@t` `Tab`|`\int_{0}^{2\pi} \sin \theta \, d\theta`|$\int_{0}^{2\pi} \sin \theta , d\theta$|
|`"` (quote key)|`\text{}`|—|
|`lVert` / `rVert`|`\lVert` / `\rVert`|$\lVert \cdot \rVert$|

Two things worth knowing about how these work rather than memorizing every trigger:

1. **`@` is the Greek-letter prefix** — `@t` → theta, and the same pattern extends to other Greek letters (this is the Gilles Castel convention the plugin is based on). Once you know the pattern you don't need to memorize each one individually.
2. **Auto-fraction is the biggest time-saver and isn't a "trigger" at all** — typing `x/y` anywhere in math mode and hitting Tab wraps it into a fraction automatically, including with parenthesized expressions like `(a+b)/(c+d)`.

Since the full snippet set is large and versioned, your fastest path to fluency is: use the two tables above for the first week, and whenever you're in Obsidian and forget a shortcut, check Settings → LaTeX Suite → Snippets directly rather than coming back to a static list — that way you're always looking at what's actually installed.


One practical note tied to your setup: once you've got LaTeX Suite installed, most of this table becomes moot for common stuff — you'd type `sr` for `^2`, `//` for a fraction, etc., using its own shorthand instead of raw LaTeX. Worth keeping this table around for the first few weeks, then switching to relying on LaTeX Suite's snippets as they become memorized, since they're faster than typing full commands.
