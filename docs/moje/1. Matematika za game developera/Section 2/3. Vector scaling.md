## Multiply Vector by another Vector/An element wise multiplication/Hadamard Product

Also called a **`Hadamard Product`**; also techically written like this with a circle:
$$
\vec{v}_{1} \circ \vec{v}_{2}
$$

In a game dev, you will se nobody using that symbol, or that name, they will use star and call it `element-wise multiplication`
$$
\vec{v}_{1} * \vec{v}_{2}
$$


Example for 2D

$$
\vec{a} \circ \vec{b} = (a.x * b.x , a.y * b.y)
$$


Example for 3D

$$
\vec{a} \circ \vec{b} = (a.x * b.x , a.y * b.y, a.z * b.z)
$$


This is less common operation and it might nort be what you want to do. For example in unity there are operators `+` and `-` that are used for addition and subtraction of Vectors, but there is operator `*` and it should be used only to multiply Vector by sclar value

In Three.js, they have `multiply` and `multiplyScalar` methods so it is more explicit

# Recap

Vector scaling lets you to adjust things like
- to adjust things like  object sizes
- do deformations (in shaders)
- perform movement calculations

2 ways
- scaling by magnitude (scalar value)
	- using single number
	- scales magnitude, preserves direction
	- sense or heading would not be erserved if scaling by negative number
- scaling by components (Element Wise/Hadamard Product)
	- scaling along each axis
	- potentially not uniform (if vector we are scaling by isn't with uniform values); means magnitude and direction potentially wouldn't be perserved
