## Point / Position / Position Vector

In game development representation of a specific location in virtual spece in the World we use  term `Point` or `Position` ; so mentioned terms are used interchangeably to refer to the same concept, a `Position Vector`; underlying concept is the same.

- often used interchangeably by gamedevs
- same idea
- underlying concept is the same

A Position Vector represent the point in the game World; representation of specific location in virtual space.
