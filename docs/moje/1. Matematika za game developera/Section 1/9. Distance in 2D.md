
# Finding distance/length/magnitude

We use **PYTHAGOREAN THEOREM** to find distance; and distance is exactly the length of the vector or the magnitude

In programming we know about sqrt function so we ca nwrite it like this

$$
c = sqrt(x^2 + y^2)
$$


Or more correct writing where $$||\vec{v}||$$
is correct symbol for **length/distance/magnitude** we write like this
$$
||\vec{v}|| = \sqrt{ a^2 + b^2}
$$
