# Conversion

degrees to radians:

`360 degs = 2PI radians`       /2

`180 degs = PI radians`        /PI

`(180 * degs) / PI = radians`


radians to degrees

`360 degs = 2PI radians`        /2

`180 degs = PI radians`         /180

`degs = (PI * radians) / 180`
