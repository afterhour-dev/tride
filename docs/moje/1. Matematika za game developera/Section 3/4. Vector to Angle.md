# How to convert from vector representation to polar coordiantes, and get that sclar value for the angle


If you have unit circle like this, where you have vector with, and you have vorrdinates for vector, how do you calculate theta angle he is making with x axis

![[2026-09-23_17-39.png]]

We will reach to linear algebra; we know that dot product relates to the angle between vectors, and we can look at x axis asa vector in this case, so two vectors are
`v = (0.707, 0.707)`  and other is `(1, 0)`

And dot product would be `0.707 * 1 + 0.707 * 0  =  0.707`

But there is geometric representation we talked about

$$
\begin{gather}
\vec{v}_{1} \cdot \vec{v_{2}} = |\lvert a\rvert| & |\lvert b\rvert| & \cos{\theta} 
\end{gather}
$$
so magnitude of one times magnitude of other vector times value of angle theta

All magnitudes are 1 since everything is on unit circle; and we just calculated dot product

`0.707 = 1 * 1 * cos(theta)`
`cos(theta)` = `0.707`

![[2026-09-23_17-51.png]]

But there was another way . 
We can do the trick by isolating the triangle and see that hypothenuse is 1, since we are on unit circle and magnitude of v vector is 1.
And cosinus is ajecent divided by hypotenuse.
Adjecent is our dot product and hypotenuse is magnitude, and it is 1.

![[2026-09-23_18-05.png]]

And as yo usee bove we got the same answer. So we calculated cosinus by two different ways and gpt the same value.

But how exactly we can get value of the angle; we have cosinus theta but not theta itself

We need to invert cosinus calculation to get original angle

![[2026-09-23_18-08.png]]

There are few functions we can invert cosine calculation to get original angle

ArcusCosinus, ArcusSinus, ArcusTangens

![[2026-09-23_18-10.png]]

# `acos` only works on top side of the circle  

If sin and cos have a mentioned problem, calculating `acos` or `asin` is also problematic

Try getting cos of the mirrored angle that is bellow x axis

# Fixing the issue with `acos`/`asin` bu using `atan2`

They realized this issue in programming 50 years ago and introduced a new function

![[2026-09-23_19-38.png]]

atan two arguments y, x (in that order) which allows splitting circle into 4 quadrons, then map the result of atan call to the appropriate sections, giving you the angle theta without restrictions of acos or similar functions

Let's go into browser console and test this

so we have cartesian x coordinate which is `0.707`, but also have cartesian y coordinate `0.707`;  remeber, our vector is (0.707, 0.707)  

So first argument is y and second is x

```ts
Math.atan2(0.707,0.707)

> 0.7853981633974483  radians
```


or to calculate angle in degrees all together

```ts
Math.atan2(0.707,0.707) * 180/ Math.PI
> 45  degrees
```


Now let's invert the y component, making the same angle like here

![[Drawing 2026-09-23 20.23.53.excalidraw|600]]

Don't forget that sinus or y component is first argument

You will get the negative value

```ts

Math.atan2(-0.707,0.707)
> -0.7853981633974483

Math.atan2(-0.707,0.707) * 180/ Math.PI
> -45
```

# How to convert polar coordinates to cartesian ones


So let's say we have radial coordinate and it is 1, and we have some value for theta angle.

First thing that pop up is that radius is 1, and radial coordinate is 1; meaning **cartesian coordinats have to be also on the circle**

![[2026-09-23_21-19.png]]

We just need to use theta angle to figure it out.

Well, we need to use cos of theta and sin of theta.

**And actually cartesian coordinates are `(cos(theta), sin(theta))`**

![[2026-09-23_21-22.png]]

But we need to take in consideration that radial corrdinate can be larger than (we just selected unit circle for this example); it is also  a hypothenusis and
`cos(theta) = adj / r` and `sin(theta) = opp / r` and `adj` and `opp` are our coordinates
which means:

`adj = r * cos(theta)` and `opp = r * sin(theta)`

So the correct calculation for corrdinates is `(r * cos(theta), r * sin(theta))`
