# General definition

we are looking triangle with adjecent (also called base) (nalaegla) side, corresponding to x axes; and we have oposite (naspramna) side, corresponding to y axis. We also have hypotenuse corresponding to the unit Vector.

![[2026-09-22_19-53.png]]

If we put our triagle into unit circle (or imagine we put it) we can see that hypotenuse is 1, and we are deviding adjecent with 1 to get cosinus and deviding opposite by 1 to get sinus, meaning sinus will be same as adjecent side length and cosinus will be same as oposite side length.

![[2026-09-22_20-21.png]]

Using unit circle makes things simple and easy to understand; just remeber than when we have uinit size hypotenuze the divisions can be ignored
